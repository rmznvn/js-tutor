## Как пользоваться

1. Открой README выбранной задачи: условие → вопросы → ответы кандидата → разбор → альтернативы.
2. Сначала попробуй решить самостоятельно.
3. В конце README раскрой эталонный код с комментариями.
4. JavaScript запускай через index.html; результаты чистых функций находятся в консоли.
5. Для React перейди в папку задачи, выполни npm ci и npm run dev.

Каждая React-задача — отдельный Vite-проект, как существующий react/task-1.
JS и React используют независимую нумерацию. Ссылки внутри README соединяют две реализации одного упражнения.
