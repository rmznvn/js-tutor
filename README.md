Да. Для задач с массивами удобно использовать один подход: сначала описать нужный результат, затем выбрать метод и только после этого писать код.
#1. Переведи условие в три вопроса
-Что приходит? Массив чисел, строк или объектов? Какие поля есть у объектов?
-Что нужно получить? Массив, один элемент, индекс, число или true/false?
-Какие ограничения? Можно ли менять исходный массив? Что делать, если совпадений нет?
