# Живые проверки пароля — React

Материал из выпуска **2026-10-05**. Время: **30–45 минут на обе версии**.

## Условие

Под полем отображаются требования с ✓ или ✗ при каждом вводе.

### Критерии готовности

- getPasswordChecks возвращает hasMinLength, hasDigit, hasNoSpaces.
- Длина минимум 8; хотя бы одна ASCII-цифра; нет обычного пробела.
- Начальное поле пустое: ✗, ✗, ✓.
- Не использовать trim: проверяем введённую строку.
- Логика отдельно от интерфейса.
- React хранит только пароль, проверки вычисляет при рендере.

### Ожидаемое поведение

| Пароль | Длина | Цифра | Без пробелов |
|---|---|---|---|
| пустой | ✗ | ✗ | ✓ |
| abcdefgh | ✓ | ✗ | ✓ |
| abcdefg1 | ✓ | ✓ | ✓ |
| abc def1 | ✓ | ✓ | ✗ |

### Крайние случаи

- Пустая строка.
- Цифра в конце.
- Пробел внутри и на краю.

2. **Интервьюер:** «Почему не хранить проверки отдельно?»

3. **Интервьюер:** «Нужен ли trim?»

Определи вход, результат и ограничения. Разбей действие на преобразование данных и отображение. Перед написанием кода предскажи результат на маленьком примере.

## Как отвечать на собеседовании

> «Чистая функция получает пароль и возвращает boolean; она подходит DOM и React.»

> «Результаты полностью определены паролем, поэтому вычислю их без трёх дополнительных состояний.»

> «Не буду удалять пробелы: это скрыло бы нарушение. Проверяю именно обычный пробел согласно условию.»

## Пошаговый разбор

1. Проверить length >= 8.
2. Перебрать символы for...of.
3. При первой цифре установить флаг и выполнить break.
4. Получить !password.includes(' ').
5. Вернуть объект.
6. DOM: слушать input и менять textContent.
7. React: хранить ввод и строить JSX из проверок.

## Типичные ошибки

- Number(' ') равен 0 и ошибочно считает пробел цифрой.
- trim скрывает ввод пользователя.
- Отдельные состояния проверок требуют синхронизации.

## Альтернативный способ

Регулярное выражение /[0-9]/.test(password) короче цикла: класс [0-9] ищет ASCII-цифру. Цикл проще объяснить на знакомых конструкциях.

## Проверка

Сопоставь результаты с таблицей выше и проверь каждый крайний случай. Для неизменяемых обновлений дополнительно проверь сохранение исходных данных и отсутствие влияния на соседние элементы.

```jsx
import { useState } from "react";

// Те же правила, что и в Javascript/task-5; функция не зависит от React.
function getPasswordChecks(password) {
  let hasDigit = false;
  for (const character of password) {
    if ("0123456789".includes(character)) {
      hasDigit = true;
      break; // После первой цифры условие выполнено.
    }
  }
  return {
    hasMinLength: password.length >= 8,
    hasDigit,
    hasNoSpaces: !password.includes(" "), // Проверяем именно обычный пробел.
  };
}
export default function PasswordChecklist() {
  const [password, setPassword] = useState("");
  // Храним только ввод; результаты всегда вычисляем из актуального пароля.
  const checks = getPasswordChecks(password);
  return (
    <section>
      <h1>Создать пароль</h1>
      <label htmlFor="password">Пароль</label>
      {/* onChange обновляет состояние; trim не применяем, чтобы не скрыть пробелы. */}
      <input id="password" type="password" autoComplete="new-password"
        aria-describedby="password-checks" value={password}
        onChange={(event) => setPassword(event.target.value)} />
      <ul id="password-checks">
        <li>{checks.hasMinLength ? "✓" : "✗"} Не менее 8 символов</li>
        <li>{checks.hasDigit ? "✓" : "✗"} Есть цифра</li>
        <li>{checks.hasNoSpaces ? "✓" : "✗"} Нет обычных пробелов</li>
      </ul>
    </section>
  );
}
```
