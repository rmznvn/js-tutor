# Корзина с изменением количества — React

Материал из выпуска **2026-09-30**. Время: **30–40 минут**.

## Условие

Пользователь выбирает количество лицензий; общая стоимость обновляется.

### Критерии готовности

- Чистая JS-функция calculateTotal(items) считает сумму price × quantity.
- Кнопки − и + меняют только выбранный товар.
- Минимальное количество — 1; кнопка − при нём disabled.
- Итог вычисляется из товаров, отдельное состояние total не нужно.
- Массив и изменяемый объект копируются.

### Ожидаемое поведение

| Действие | Итого |
|---|---:|
| Начальное состояние: 1 × 1500 + 2 × 2500 | 6500 ₽ |
| BIM Viewer увеличить до 2 | 8000 ₽ |
| Из исходного состояния Document Manager уменьшить до 1 | 4000 ₽ |
| Пустой массив в calculateTotal | 0 |

### Крайние случаи

- Количество не падает ниже 1.
- Изменение первого товара сохраняет второй.
- Пустой массив даёт сумму 0.

3. **Интервьюер:** «Достаточно ли disabled для минимума количества?»

Определи вход, результат и ограничения. Разбей действие на преобразование данных и отображение. Перед написанием кода предскажи результат на маленьком примере.

## Как отвечать на собеседовании

> «Буду хранить товары с количеством. Итог вычислю через reduce из текущего массива, чтобы не синхронизировать два состояния.»

> «Применю map; для совпавшего ID создам {...item, quantity: новоеКоличество}, остальные объекты верну как есть.»

> «Ограничу значение через Math.max также в функции обновления, чтобы правило действовало при любом её вызове.»

## Пошаговый разбор

1. Объявить товары в useState.
2. Вынести calculateTotal в обычную функцию.
3. Передавать в обработчик id и delta.
4. Функционально обновлять массив через map.
5. Ограничить quantity единицей.
6. В JSX вычислять стоимость позиции и общий итог.

## Типичные ошибки

- Изменение item.quantity напрямую мутирует объект.
- Отдельный total требует ручной синхронизации.
- push/splice не подходят для прямого изменения состояния.

## Альтернативный способ

Сумму можно считать циклом for...of. Он явно показывает локальный аккумулятор; reduce компактно выражает получение одного итога. Оба способа не меняют товары.

## Проверка

Сопоставь результаты с таблицей выше и проверь каждый крайний случай. Для неизменяемых обновлений дополнительно проверь сохранение исходных данных и отсутствие влияния на соседние элементы.

```jsx
import { useState } from "react";

const initialItems = [
  { id: 1, name: "BIM Viewer", price: 1500, quantity: 1 },
  { id: 2, name: "Document Manager", price: 2500, quantity: 2 },
];
// Чистая функция: итог — сумма price * quantity.
// Начальное 0 также обеспечивает результат 0 для пустой корзины.
function calculateTotal(items) {
  return items.reduce((total, item) => total + item.price * item.quantity, 0);
}
// Альтернатива reduce: обычный цикл с локальным аккумулятором.
function calculateTotalWithLoop(items) {
  let total = 0;
  for (const item of items) total += item.price * item.quantity;
  return total;
}

export default function Cart() {
  const [items, setItems] = useState(initialItems);
  // Итог вычисляем из товаров: отдельное состояние не требуется.
  const total = calculateTotal(items);
  function changeQuantity(id, delta) {
    // Функциональное обновление использует актуальное предыдущее состояние.
    setItems((currentItems) => currentItems.map((item) => {
      if (item.id !== id) return item;
      // Копируем изменяемый объект; минимум 1 защищаем также в обработчике.
      return { ...item, quantity: Math.max(1, item.quantity + delta) };
    }));
  }
  return (
    <section>
      <h1>Корзина</h1>
      <ul>
        {items.map((item) => (
          <li key={item.id}>
            <h2>{item.name}</h2>
            <p>Цена лицензии: {item.price} ₽</p>
            {/* disabled ограничивает доступное действие в интерфейсе. */}
            <button type="button" disabled={item.quantity === 1}
              aria-label={`Уменьшить количество ${item.name}`}
              onClick={() => changeQuantity(item.id, -1)}>−</button>
            <span> {item.quantity} </span>
            <button type="button" aria-label={`Увеличить количество ${item.name}`}
              onClick={() => changeQuantity(item.id, 1)}>+</button>
            <p>Стоимость: {item.price * item.quantity} ₽</p>
          </li>
        ))}
      </ul>
      <p><strong>Итого: {total} ₽</strong></p>
      {/* Проверка альтернативы остаётся вычислением, без изменения состояния. */}
      <small>Проверка циклом: {calculateTotalWithLoop(items)} ₽</small>
    </section>
  );
}
```
