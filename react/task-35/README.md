# React: удаление карточек из пагинации
Выпуск: 9 ноября 2026.

## Условие
Материалы: 1 «Основы CMS», 2 «Формы React», 3 «События DOM», 4 «Методы массивов», 5 «Доступность». На странице по 2 материала, старт — первая страница.
Добавь Назад/Далее, номер страницы, количество и удаление каждой карточки.
Если текущая страница после удаления существует, останься на ней. Если исчезла, перейди на последнюю существующую. Не сбрасывай всегда на первую.
При пустом списке покажи «Список пуст», «Страница 0 из 0», заблокируй навигацию. Кнопка «Восстановить список» возвращает исходные 5 материалов и первую страницу.
Готово: состояние содержит список и страницу; удаление корректирует их одним функциональным обновлением; видимые карточки и количество страниц вычисляются, useEffect не нужен.
Крайние случаи: удалить единственную карточку третьей страницы; удалить одну из двух карточек, когда страница ещё существует; удалить всё и восстановить.
Время: 25–35 минут.

## Как рассуждать
1. Может ли номер страницы перестать существовать?
2. Когда известен новый размер списка?
3. Какие данные нужно хранить, а какие вычислять?

## Примеры ответов вслух
«После удаления пятого материала третья страница исчезнет. Новый номер ограничу последней существующей страницей, но не буду сбрасывать его без причины на первую».
«В функциональном setter сначала получу новый массив через filter, затем количество страниц и допустимый номер. Верну согласованный объект одним обновлением».
«Храню items/page; pageCount и slice вычисляю. Причина изменения известна в обработчике удаления, отдельный useEffect не нужен».
«Для пустого списка внутренний номер сохраню 1, но выведу 0 из 0. Обе кнопки заблокируются. Проверю исчезновение страницы, сохранение существующей и восстановление».

## Пошаговый разбор
1. Создай state со списком и page.
2. Вычисли pageCount и видимые карточки через slice.
3. При удалении получи новый список.
4. Вычисли новые границы.
5. Ограничь старый page сверху новым максимумом, сохранив минимум 1.
6. Выведи пустое состояние и заблокируй недопустимые переходы.
7. Для восстановления верни исходные данные и page=1.

Ошибки: удалить запись без изменения page; всегда сбрасывать на 1; вызвать setter внутри render; мутировать исходный массив; считать страницу 1 из 0 допустимой подписью.
Проверки: перейти на 3 → удалить ID5 → 2 из 2, ID3/4; удалить ID4 → всё ещё 2 из 2, ID3; удалить ID3 → 1 из 1, ID1/2; удалить всё → 0 из 0; восстановить → 1 из 3.
Альтернатива: хранить запрошенный page и вычислять допустимый displayedPage при рендере. Удобно, если нужно сохранять предпочтение пользователя, но состояние и экран могут расходиться. Здесь корректируем page в событии, чтобы состояние соответствовало интерфейсу.

## Запуск
npm ci, npm run dev. В Codespaces: npm run dev -- --host 0.0.0.0 и открой порт.

### src/App.jsx

```jsx
import { useState } from "react";

const PAGE_SIZE = 2;
const initialItems = [
  { id: 1, title: "Основы CMS" },
  { id: 2, title: "Формы React" },
  { id: 3, title: "События DOM" },
  { id: 4, title: "Методы массивов" },
  { id: 5, title: "Доступность" },
];

export default function DeletablePagination() {
  // Список и страница обновляются совместно: удаление влияет на границы.
  const [state, setState] = useState({ items: initialItems, page: 1 });
  const pageCount = Math.ceil(state.items.length / PAGE_SIZE);
  const start = (state.page - 1) * PAGE_SIZE;
  const visibleItems = state.items.slice(start, start + PAGE_SIZE);

  function removeItem(id) {
    setState((current) => {
      const items = current.items.filter((item) => item.id !== id);
      const nextPageCount = Math.ceil(items.length / PAGE_SIZE);

      // Сохраняем страницу, пока она существует.
      // Если последняя исчезла, переходим на ближайшую существующую.
      // Для пустого списка внутренний номер остаётся 1.
      const page = Math.min(current.page, Math.max(nextPageCount, 1));
      return { items, page };
    });
  }

  function changePage(delta) {
    setState((current) => {
      const count = Math.ceil(current.items.length / PAGE_SIZE);
      const page = Math.min(
        Math.max(current.page + delta, 1),
        Math.max(count, 1)
      );
      return { ...current, page };
    });
  }

  return (
    <main>
      <h1>Материалы</h1>
      <p>Всего: {state.items.length}</p>
      {state.items.length === 0 ? <p>Список пуст</p> : (
        <ul>
          {visibleItems.map((item) => (
            <li key={item.id}>
              {item.title}{" "}
              <button
                type="button"
                aria-label={"Удалить: " + item.title}
                onClick={() => removeItem(item.id)}
              >
                Удалить
              </button>
            </li>
          ))}
        </ul>
      )}
      <nav aria-label="Страницы материалов">
        <button type="button" disabled={state.page <= 1} onClick={() => changePage(-1)}>
          Назад
        </button>
        <span role="status">
          Страница {pageCount === 0 ? 0 : state.page} из {pageCount}
        </span>
        <button type="button" disabled={state.page >= pageCount} onClick={() => changePage(1)}>
          Далее
        </button>
      </nav>
      <button
        type="button"
        // Исходный массив не мутировали: можно использовать его снова.
        onClick={() => setState({ items: initialItems, page: 1 })}
      >
        Восстановить список
      </button>
    </main>
  );
}
```
