# Список задач перед публикацией — React

Материал из выпуска **2026-10-05**. Время: **30–40 минут**.

## Условие

Разработчик отмечает проверки и удаляет ненужные пункты.

### Критерии готовности

- TaskList хранит задачи; TaskItem получает задачу и callbacks через props.
- Checkbox переключает done только выбранной задачи.
- Удаление исключает выбранную задачу.
- Счётчик «Выполнено: 1 из 3» вычисляется из массива.
- После удаления всех — «Список пуст».
- Обновления без мутаций.

### Ожидаемое поведение

| Действие | Статистика |
|---|---|
| Начало | 1 из 3 |
| Удалить выполненную задачу 2 | 0 из 2 |
| Удалить все | 0 из 0; Список пуст |

### Крайние случаи

- Повторное переключение.
- Удаление выполненного пункта.
- Удаление всех.

## Как отвечать на собеседовании

> «В TaskList, потому что список и статистика используют одинаковые данные.»

> «Передам callbacks через props; TaskItem вызовет нужный callback с ID, не изменяя props.»

> «map нужен для замены одного объекта без изменения длины; filter — для исключения объекта.»

## Пошаговый разбор

2. Получить completedCount через filter().length.
3. Функционально обновлять через map и копию объекта.
4. Удалять через filter.
5. Передать данные/обработчики ребёнку.
6. Условно отобразить пустой список.

## Типичные ошибки

- task.done = !task.done мутирует объект.
- Копии массива недостаточно, если затем менять вложенный объект.
- Отдельный счётчик может рассинхронизироваться.

## Альтернативный способ

Отдельный массив выполненных ID удобен для постоянных задач. Здесь задачи удаляются, поэтому done внутри объекта упрощает согласованность.

## Проверка

Сопоставь результаты с таблицей выше и проверь каждый крайний случай. Для неизменяемых обновлений дополнительно проверь сохранение исходных данных и отсутствие влияния на соседние элементы.

```jsx
import { useState } from "react";

const initialTasks = [
  { id: 1, title: "Проверить мобильную версию", done: false },
  { id: 2, title: "Проверить ссылки", done: true },
  { id: 3, title: "Проверить форму заявки", done: false },
];
// Ребёнок получает данные и callbacks, не изменяет props.
function TaskItem({ task, onToggle, onDelete }) {
  return (
    <li>
      <label>
        {/* checked управляется полем done, callback сообщает родителю ID. */}
        <input type="checkbox" checked={task.done} onChange={() => onToggle(task.id)} />
        {task.title}
      </label>
      <button type="button" onClick={() => onDelete(task.id)}>Удалить</button>
    </li>
  );
}
export default function TaskList() {
  const [tasks, setTasks] = useState(initialTasks);
  // Производное значение: не требуется синхронизация отдельного счётчика.
  const completedCount = tasks.filter((task) => task.done).length;
  function toggleTask(id) {
    setTasks((currentTasks) => currentTasks.map((task) => {
      if (task.id !== id) return task;
      // Новый массив и копия изменяемого объекта обеспечивают неизменяемость.
      return { ...task, done: !task.done };
    }));
  }
  function deleteTask(id) {
    // filter исключает выбранный ID и сохраняет остальные задачи.
    setTasks((currentTasks) => currentTasks.filter((task) => task.id !== id));
  }
  return (
    <section>
      <h1>Проверки перед публикацией</h1>
      <p>Выполнено: {completedCount} из {tasks.length}</p>
      {tasks.length === 0 ? <p>Список пуст</p> : (
        <ul>
          {tasks.map((task) => (
            <TaskItem key={task.id} task={task} onToggle={toggleTask} onDelete={deleteTask} />
          ))}
        </ul>
      )}
    </section>
  );
}
```
