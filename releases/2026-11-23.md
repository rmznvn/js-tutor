# Practice release — November 23, 2026

This release contains exactly four distinct exercises: two JavaScript tasks and two React tasks.

## 1. Conditions for all four exercises

### JavaScript task 46 — Independent reservation hold timers

**Difficulty:** Junior+. **Main topic:** closures and timers. Build a reusable factory whose independent instances can start, restart, cancel and expire. Calculate remaining time from an absolute deadline and connect two timers to the DOM. Edge cases: repeated start, inactive cancel, delayed interval. Estimated time: 45–60 minutes.

### JavaScript task 47 — Effective team permissions

**Difficulty:** Junior+. **Main topic:** Maps and Sets. Combine role and custom permissions, remove explicit denials, handle unknown roles, remove duplicates and sort without mutation. Edge cases: missing optional arrays, duplicated permissions, unknown role. Estimated time: 40–55 minutes.

### React task 47 — Conference agenda planner

**Difficulty:** Junior+. **Main topic:** derived state with Date and Intl. Edit a start time and session durations; derive every start/end label, total duration and validation warnings. Edge cases: empty time, invalid duration, exact versus exceeded budget. Estimated time: 45–60 minutes.

### React task 48 — Volunteer availability matrix

**Difficulty:** Junior+. **Main topic:** nested immutable state. Toggle controlled availability cells, derive coverage and warn about uncovered shifts. Edge cases: missing volunteer entry, final coverage removed, all shifts covered. Estimated time: 40–55 minutes.

## 2. Interview hints: how to reason

### Task 46

Clarify restart and cancellation behavior. Each factory invocation needs private interval and deadline values. Store a deadline instead of decrementing a counter because interval execution may be delayed.

### Task 47 JavaScript

Clarify rule priority. Use Map for keyed role lookup and Set for uniqueness and membership. Apply denials last. Keep a compatibility fallback for modern non-mutating sorting.

### Task 47 React

Store only editable input values. Derive schedule rows, totals and warnings. Validate the controlled time string before constructing dates, and separate arithmetic from localized formatting.

### Task 48 React

Clarify the many-to-many relationship. Model selections by stable volunteer and shift IDs. Copy the changed nested array and outer object; derive coverage from the single state source.

## 3. Example candidate answers

### Task 46

> Each factory call creates its own lexical environment, so the timers do not share interval state. I calculate from a deadline because setInterval is not an exact clock and delayed callbacks should not accumulate drift.

### Task 47 JavaScript

> Map expresses role lookup and Set removes duplicate permissions. JavaScript passes the array reference value, but spreading reads its elements into a new Set and does not mutate the source array.

### Task 47 React

> I keep the start time and editable sessions in state. Start/end labels and totals are derived, because storing them would duplicate information and create synchronization bugs.

### Task 48 React

> The functional update reads the latest state and returns a new inner array and outer object. Coverage is derived, so it cannot drift out of sync with selections.

## 4. Step-by-step breakdown

### Task 46

Format seconds; create private closure state; safely clear intervals; calculate from the deadline; call tick/expiry/cancel callbacks; create independent DOM instances. Common errors: global interval ID, duplicate intervals, repeated expiry. Alternative: a class with instance fields.

### Task 47 JavaScript

Look up the role; default missing arrays; combine in a Set; delete denials; convert and sort non-destructively; render. Common errors: wrong rule order, mutating role arrays, assuming Set compares objects by value. Alternative: a plain object permission matrix.

### Task 47 React

Validate time; parse hours/minutes; advance a cursor Date; format with Intl; update one session immutably; derive totals and warnings. Common errors: duplicated schedule state, mutation, treating empty time as midnight. Alternative: minutes-since-midnight arithmetic.

### Task 48 React

Store arrays of shift IDs by volunteer; toggle using filter/spread; copy the outer object; derive coverage and warnings; render an accessible table. Common errors: push mutation, shallow outer copy with inner mutation, duplicated coverage state. Alternative: an array of volunteer/shift pairs.

### JavaScript task 46 — JavaScript

```js
function formatTime(totalSeconds) {
  // Clamp invalid negative time so an expired timer always renders as 00:00.
  const safeSeconds = Math.max(0, Math.floor(totalSeconds));
  const minutes = Math.floor(safeSeconds / 60);
  const seconds = safeSeconds % 60;

  return `${String(minutes).padStart(2, "0")}:${String(seconds).padStart(2, "0")}`;
}

function createReservationTimer({
  durationSeconds = 60,
  onTick = () => {},
  onExpire = () => {},
  onCancel = () => {},
}) {
  // These variables remain private inside the closure of this timer instance.
  let intervalId = null;
  let deadline = null;

  function stopInterval() {
    if (intervalId !== null) {
      clearInterval(intervalId);
      intervalId = null;
    }
  }

  function getRemainingSeconds() {
    if (deadline === null) return durationSeconds;

    // Calculate from an absolute deadline so delayed intervals do not accumulate drift.
    return Math.max(0, Math.ceil((deadline - Date.now()) / 1000));
  }

  function tick() {
    const remainingSeconds = getRemainingSeconds();
    onTick(remainingSeconds);

    if (remainingSeconds === 0) {
      stopInterval();
      deadline = null;
      onExpire();
    }
  }

  function start() {
    // Restarting replaces the previous interval instead of creating a second one.
    stopInterval();
    deadline = Date.now() + durationSeconds * 1000;
    onTick(durationSeconds);
    intervalId = setInterval(tick, 250);
  }

  function cancel() {
    const wasRunning = intervalId !== null;
    stopInterval();
    deadline = null;
    onTick(durationSeconds);

    if (wasRunning) onCancel();
  }

  return {
    start,
    cancel,
    getRemainingSeconds,
  };
}

function connectTimer({ durationSeconds, timeSelector, startSelector, cancelSelector, label }) {
  const timeElement = document.querySelector(timeSelector);
  const statusElement = document.querySelector("#status");

  const timer = createReservationTimer({
    durationSeconds,
    onTick: (seconds) => {
      timeElement.textContent = formatTime(seconds);
    },
    onExpire: () => {
      statusElement.textContent = `${label} hold expired.`;
    },
    onCancel: () => {
      statusElement.textContent = `${label} hold cancelled.`;
    },
  });

  document.querySelector(startSelector).addEventListener("click", () => {
    timer.start();
    statusElement.textContent = `${label} hold started.`;
  });

  document.querySelector(cancelSelector).addEventListener("click", timer.cancel);
  timeElement.textContent = formatTime(durationSeconds);

  return timer;
}

// Each call creates an independent closure with its own interval and deadline.
connectTimer({
  durationSeconds: 10,
  timeSelector: "#studio-time",
  startSelector: "#studio-start",
  cancelSelector: "#studio-cancel",
  label: "Studio room",
});

connectTimer({
  durationSeconds: 15,
  timeSelector: "#workshop-time",
  startSelector: "#workshop-start",
  cancelSelector: "#workshop-cancel",
  label: "Workshop room",
});

console.assert(formatTime(65) === "01:05", "65 seconds must format as 01:05");
console.assert(formatTime(-3) === "00:00", "Negative time must be clamped");
```

```js
const rolePermissions = new Map([
  ["viewer", ["project:view", "comment:view"]],
  ["editor", ["project:view", "comment:view", "comment:create", "project:edit"]],
  ["manager", ["project:view", "comment:view", "project:edit", "member:invite"]],
]);

const users = [
  { id: 1, name: "Aisha", role: "viewer", customPermissions: ["comment:create"] },
  { id: 2, name: "Mateo", role: "editor", deniedPermissions: ["project:edit"] },
  { id: 3, name: "Noor", role: "manager", customPermissions: ["report:export"] },
  { id: 4, name: "Unknown role", role: "contractor" },
];

function sortWithoutMutation(values) {
  // toSorted is the modern non-mutating method; the fallback supports older targets.
  return typeof values.toSorted === "function"
    ? values.toSorted()
    : [...values].sort();
}

function getEffectivePermissions(user, permissionsByRole = rolePermissions) {
  const {
    role,
    customPermissions = [],
    deniedPermissions = [],
  } = user;

  // Unknown roles safely receive an empty permission array.
  const inheritedPermissions = permissionsByRole.get(role) ?? [];

  // Set removes duplicates while combining role and custom permissions.
  const effectivePermissions = new Set([
    ...inheritedPermissions,
    ...customPermissions,
  ]);

  // Explicit denials win over inherited and custom permissions.
  for (const permission of deniedPermissions) {
    effectivePermissions.delete(permission);
  }

  return sortWithoutMutation([...effectivePermissions]);
}

function renderUserOptions() {
  const select = document.querySelector("#user-select");

  users.forEach(({ id, name, role }) => {
    select.append(new Option(`${name} — ${role}`, String(id)));
  });
}

function renderPermissions(userId) {
  const user = users.find(({ id }) => id === Number(userId));
  const list = document.querySelector("#permission-list");
  const summary = document.querySelector("#summary");

  list.innerHTML = "";

  if (!user) {
    summary.textContent = "User not found.";
    return;
  }

  const permissions = getEffectivePermissions(user);

  permissions.forEach((permission) => {
    const item = document.createElement("li");
    item.textContent = permission;
    list.append(item);
  });

  summary.textContent = permissions.length
    ? `${permissions.length} effective permission(s).`
    : "This user has no effective permissions.";
}

document.querySelector("#user-select").addEventListener("change", (event) => {
  renderPermissions(event.target.value);
});

renderUserOptions();
renderPermissions(users.at(0).id);

console.assert(
  getEffectivePermissions(users[1]).includes("project:edit") === false,
  "Explicit denial must remove an inherited permission"
);
console.assert(
  getEffectivePermissions(users[3]).length === 0,
  "An unknown role must be handled safely"
);
```

### React task 47

```jsx
import { useState } from "react";

const timeFormatter = new Intl.DateTimeFormat("en-GB", {
  hour: "2-digit",
  minute: "2-digit",
  hour12: false,
});

const initialSessions = [
  { id: 1, title: "Opening", durationMinutes: 15 },
  { id: 2, title: "Product demo", durationMinutes: 35 },
  { id: 3, title: "Questions", durationMinutes: 20 },
];

function createSchedule(startTime, sessions) {
  // An empty or incomplete controlled time input cannot create a valid schedule.
  if (!/^\d{2}:\d{2}$/.test(startTime)) return [];

  const [hours, minutes] = startTime.split(":").map(Number);

  // Use a fixed calendar date because only the time-of-day matters in this exercise.
  const cursor = new Date(2026, 0, 1, hours, minutes);

  if (Number.isNaN(cursor.getTime())) return [];

  return sessions.map((session) => {
    const start = new Date(cursor);
    cursor.setMinutes(cursor.getMinutes() + session.durationMinutes);
    const end = new Date(cursor);

    return {
      ...session,
      startLabel: timeFormatter.format(start),
      endLabel: timeFormatter.format(end),
    };
  });
}

export default function App() {
  const [startTime, setStartTime] = useState("09:00");
  const [sessions, setSessions] = useState(initialSessions);

  function updateDuration(sessionId, nextValue) {
    const durationMinutes = Number(nextValue);

    setSessions((currentSessions) =>
      currentSessions.map((session) =>
        session.id === sessionId
          ? { ...session, durationMinutes }
          : session
      )
    );
  }

  // Totals and calculated start/end labels are derived from actual state.
  const totalMinutes = sessions.reduce(
    (total, session) => total + session.durationMinutes,
    0
  );
  const schedule = createSchedule(startTime, sessions);
  const hasInvalidDuration = sessions.some(
    ({ durationMinutes }) => !Number.isFinite(durationMinutes) || durationMinutes < 5
  );
  const exceedsBudget = totalMinutes > 90;

  return (
    <main>
      <h1>Conference agenda planner</h1>

      <label>
        Agenda start time
        <input
          type="time"
          value={startTime}
          onChange={(event) => setStartTime(event.target.value)}
        />
      </label>

      <ul>
        {schedule.map((session) => (
          <li key={session.id}>
            <strong>{session.title}</strong>: {session.startLabel}–{session.endLabel}
            <label>
              Duration
              <input
                type="number"
                min="5"
                step="5"
                value={session.durationMinutes}
                onChange={(event) => updateDuration(session.id, event.target.value)}
              />
              minutes
            </label>
          </li>
        ))}
      </ul>

      <p>Total: {totalMinutes} minutes of a 90-minute budget.</p>

      {hasInvalidDuration && (
        <p role="alert">Every session must last at least 5 minutes.</p>
      )}

      {exceedsBudget && (
        <p role="alert">The agenda exceeds the budget by {totalMinutes - 90} minutes.</p>
      )}
    </main>
  );
}
```

### React task 48

```jsx
import { useState } from "react";

const volunteers = [
  { id: "ava", name: "Ava" },
  { id: "ben", name: "Ben" },
  { id: "chloe", name: "Chloe" },
];

const shifts = [
  { id: "morning", label: "Morning" },
  { id: "afternoon", label: "Afternoon" },
  { id: "evening", label: "Evening" },
];

const initialAvailability = {
  ava: ["morning"],
  ben: ["afternoon"],
  chloe: [],
};

export default function App() {
  // Each object property contains the shift IDs selected by one volunteer.
  const [availability, setAvailability] = useState(initialAvailability);

  function toggleAvailability(volunteerId, shiftId) {
    setAvailability((currentAvailability) => {
      const currentShifts = currentAvailability[volunteerId] ?? [];
      const isSelected = currentShifts.includes(shiftId);

      // Create both a new nested array and a new outer object.
      const nextShifts = isSelected
        ? currentShifts.filter((id) => id !== shiftId)
        : [...currentShifts, shiftId];

      return {
        ...currentAvailability,
        [volunteerId]: nextShifts,
      };
    });
  }

  // Coverage is derived, so no second state value can drift out of sync.
  const coverage = Object.fromEntries(
    shifts.map((shift) => [
      shift.id,
      volunteers.filter((volunteer) =>
        (availability[volunteer.id] ?? []).includes(shift.id)
      ).length,
    ])
  );

  const uncoveredShifts = shifts.filter((shift) => coverage[shift.id] === 0);
  const totalSelections = Object.values(availability).reduce(
    (total, selectedShifts) => total + selectedShifts.length,
    0
  );

  return (
    <main>
      <h1>Volunteer availability matrix</h1>

      <table>
        <thead>
          <tr>
            <th scope="col">Volunteer</th>
            {shifts.map((shift) => (
              <th scope="col" key={shift.id}>{shift.label}</th>
            ))}
          </tr>
        </thead>
        <tbody>
          {volunteers.map((volunteer) => (
            <tr key={volunteer.id}>
              <th scope="row">{volunteer.name}</th>
              {shifts.map((shift) => {
                const isChecked = (availability[volunteer.id] ?? [])
                  .includes(shift.id);

                return (
                  <td key={shift.id}>
                    <input
                      type="checkbox"
                      checked={isChecked}
                      aria-label={`${volunteer.name} is available for ${shift.label}`}
                      onChange={() => toggleAvailability(volunteer.id, shift.id)}
                    />
                  </td>
                );
              })}
            </tr>
          ))}
        </tbody>
      </table>

      <h2>Coverage</h2>
      <ul>
        {shifts.map((shift) => (
          <li key={shift.id}>
            {shift.label}: {coverage[shift.id]} volunteer(s)
          </li>
        ))}
      </ul>

      <p>{totalSelections} availability selection(s) in total.</p>

      {uncoveredShifts.length > 0 && (
        <p role="alert">
          No coverage: {uncoveredShifts.map(({ label }) => label).join(", ")}.
        </p>
      )}
    </main>
  );
}
```
