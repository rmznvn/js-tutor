# Practice release — November 27, 2026

Exactly four independent exercises: two JavaScript and two React.

## 1. Conditions

### JavaScript 50 — Closure-based inventory ledger
**Topics:** closures, Map, references, validation. **Difficulty:** confident junior+. **Time:** 45–60 minutes.

Create an equipment reservation form backed by a factory. Input records contain id, name, and available quantity. Reserve and release positive integer quantities, reject unknown products and over-reservation, keep the Map private, and return snapshots that outside code cannot use to mutate internal values.

**Ready when:** private stock is unreachable except through methods; the source records and returned snapshots cannot alter the ledger; DOM updates after successful actions.  
**Edges:** zero/decimal quantity, unknown id, insufficient stock.

### JavaScript 51 — Accessibility audit queue
**Topics:** flatMap, Map, Set, sorting. **Difficulty:** junior+. **Time:** 40–55 minutes.

Nested audits contain pages, sections, and issues. Flatten them into one unresolved queue, attach page and section context, deduplicate types, count issues by severity, and sort high before medium before low.

**Ready when:** source data is unchanged; empty nested arrays work; unknown severity sorts last; empty results render clearly.  
**Edges:** all resolved, missing sections/issues, repeated issue types.

### React 51 — Kanban workflow transitions
**Topics:** immutable updates, derived collections, child callbacks. **Difficulty:** junior+. **Time:** 45–60 minutes.

Render Backlog, In progress, and Done columns from one ticket array. Move a ticket exactly one step, disable boundary buttons, and derive each column and count.

**Ready when:** only the moved ticket is copied; columns are not separate state; empty columns render a message.  
**Edges:** first/last status, empty column, repeated moves.

### React 52 — Exact shared-bill balances
**Topics:** controlled inputs, derived state, integer cents, Intl. **Difficulty:** junior+ to middle. **Time:** 50–70 minutes.

Three people enter payments. Derive total, exact target shares, and balances. Show who owes, who should receive, or who is settled. Work in integer cents and distribute indivisible remainder cents deterministically.

**Ready when:** input strings remain controlled; invalid/negative input shows an error; target cents sum exactly to total; no balance state is stored.  
**Edges:** zero total, invalid value, total not divisible by participant count.

## 2. Interview hints and first-person answers

### JS 50
Ask whether release can exceed original stock, whether ids are unique, and whether callers may edit snapshots. Keep the Map in the factory scope and expose narrow methods.

**Candidate answer:** “The returned methods close over stock, so the Map remains reachable while the ledger exists but callers cannot access it directly. I copy input records into Map values and return fresh snapshot objects. JavaScript passes the object-reference value; reassignment and mutation are different, so these copies prevent outside mutation from changing internal state.”

**Checkpoint:** changing initialStock after factory creation must not affect the ledger. Changing a snapshot must not affect the next snapshot.

### JS 51
Ask whether resolved issues remain visible, define severity order, and confirm whether repeated types should be unique. Use two flatMap calls because there are two nested collection levels.

**Candidate answer:** “The first flatMap expands pages into sections, and the second expands sections into issues while adding context. Set models unique types; Map models counts keyed by severity. I copy before sorting so I never mutate source data.”

### React 51
Ask whether movement skips statuses and what happens at boundaries. Store tickets only and derive columns.

**Candidate answer:** “The ticket status is the source of truth. Separate column state would duplicate information. The parent owns the move callback, while cards receive the ticket and callback through props. map returns a new array and copies only the matching ticket.”

### React 52
Ask how rounding should work and whether blank input is temporarily allowed. Parse only for derivation and keep controlled values as strings.

**Candidate answer:** “Binary floating-point can make currency totals surprising, so I convert each valid payment to integer cents. I calculate a base share and distribute leftover cents in a stable order. Total and balances are derived from people, so they cannot become stale.”

## 3. Breakdowns, mistakes, checks, alternatives

### JS 50
1. Copy input into a private Map.
2. Centralize validation in one change function.
3. Use direction -1 for reserve and +1 for release.
4. Replace Map value objects.
5. Return fresh snapshots and render them.

**Mistakes:** exposing the Map, mutating caller objects, accepting decimals, dynamic method name from untrusted input.  
**Checks:** reserve all stock, over-reserve, release, mutate snapshot.  
**Alternative:** a class with private fields provides similar encapsulation but adds class syntax beyond this exercise.

### JS 51
1. Flatten pages to sections and sections to contextual issues.
2. Filter resolved entries.
3. Create unique types with Set.
4. Count severity with Map and nullish fallback.
5. Sort by rank and page.
6. Render summary and list.

**Mistakes:** map without flattening, using an array for uniqueness, forgetting empty defaults, mutating source sort.  
**Checks:** empty arrays, repeated type, unknown severity, no open issues.  
**Alternative:** nested for-of loops are more verbose but easier to pause and inspect during debugging.

### React 51
1. Store one ticket array.
2. Find current status index.
3. Reject an out-of-range next index.
4. Copy the selected ticket.
5. Derive columns with map and filter.
6. Disable impossible controls.

**Mistakes:** three column states, mutation, array-index keys, allowing skipped states.  
**Checks:** move both directions, reach boundaries, empty a column.  
**Alternative:** nested column arrays suit future drag-and-drop but complicate this simple transition.

### React 52
1. Keep input values as strings.
2. Validate and convert to cents.
3. Sum with reduce.
4. Calculate base share and remainder.
5. Assign exact target cents.
6. Derive signed balances and format only for display.

**Mistakes:** arithmetic directly on strings, floating-point equality, rounded shares that do not sum to total, stored balances.  
**Checks:** all zeros, 60 split by 3, 10 split by 3, negative/invalid input.  
**Alternative:** assign all rounding difference to the final participant; simpler, but less evenly distributed.

### JavaScript 50 script

```js
const initialStock = [
  { id: "camera", name: "Camera", available: 3 },
  { id: "tripod", name: "Tripod", available: 5 },
  { id: "mic", name: "Microphone", available: 2 },
];

function createInventoryLedger(items = []) {
  // The Map is reachable only through the returned methods: the closure protects it.
  const stock = new Map(
    items.map(({ id, name, available }) => [id, { name, available }]),
  );

  function change(productId, rawQuantity, direction) {
    const quantity = Number(rawQuantity);
    const product = stock.get(productId);

    if (!product) return { ok: false, message: "Unknown product." };
    if (!Number.isInteger(quantity) || quantity <= 0) {
      return { ok: false, message: "Quantity must be a positive integer." };
    }
    if (direction === -1 && quantity > product.available) {
      return { ok: false, message: `Only ${product.available} available.` };
    }

    // Replace the value object instead of mutating the existing object in the Map.
    const nextAvailable = product.available + direction * quantity;
    stock.set(productId, { ...product, available: nextAvailable });

    return {
      ok: true,
      message: direction === -1 ? `Reserved ${quantity}.` : `Released ${quantity}.`,
    };
  }

  return {
    reserve(productId, quantity) {
      return change(productId, quantity, -1);
    },
    release(productId, quantity) {
      return change(productId, quantity, 1);
    },
    getSnapshot() {
      // Return fresh objects so callers cannot mutate the private Map values.
      return [...stock].map(([id, product]) => ({ id, ...product }));
    },
  };
}

const ledger = createInventoryLedger(initialStock);
const form = document.querySelector("#inventory-form");
const productSelect = document.querySelector("#product");
const quantityInput = document.querySelector("#quantity");
const message = document.querySelector("#message");
const stockList = document.querySelector("#stock-list");

function render() {
  const snapshot = ledger.getSnapshot();
  stockList.replaceChildren();
  productSelect.replaceChildren();

  snapshot.forEach((product) => {
    const option = document.createElement("option");
    option.value = product.id;
    option.textContent = product.name;
    productSelect.append(option);

    const item = document.createElement("li");
    item.textContent = `${product.name}: ${product.available} available`;
    stockList.append(item);
  });
}

form.addEventListener("submit", (event) => {
  event.preventDefault();
  const action = event.submitter?.value;
  const method = action === "release" ? "release" : "reserve";
  const result = ledger[method](productSelect.value, quantityInput.value);
  message.textContent = result.message;
  if (result.ok) render();
});

render();

// Explain-why checkpoint: changing initialStock later cannot reach the private Map,
// and changing an object returned by getSnapshot cannot change the ledger either.
```

### JavaScript 51 script

```js
const audits = [
  { page: "/checkout", sections: [
    { name: "Form", issues: [
      { id: "a1", type: "label", severity: "high", resolved: false },
      { id: "a2", type: "contrast", severity: "medium", resolved: true },
    ] },
  ] },
  { page: "/account", sections: [
    { name: "Navigation", issues: [
      { id: "a3", type: "keyboard", severity: "high", resolved: false },
      { id: "a4", type: "label", severity: "low", resolved: false },
    ] },
    { name: "Profile", issues: [] },
  ] },
];

function prepareAuditQueue(pageAudits) {
  const severityRank = new Map([["high", 0], ["medium", 1], ["low", 2]]);

  const unresolved = pageAudits
    .flatMap(({ page, sections = [] }) =>
      sections.flatMap(({ name: section, issues = [] }) =>
        issues.map((issue) => ({ ...issue, page, section })),
      ),
    )
    .filter((issue) => !issue.resolved);

  const types = new Set(unresolved.map((issue) => issue.type));
  const countsBySeverity = new Map();

  unresolved.forEach(({ severity }) => {
    countsBySeverity.set(severity, (countsBySeverity.get(severity) ?? 0) + 1);
  });

  const sortedIssues = [...unresolved].sort(
    (a, b) =>
      (severityRank.get(a.severity) ?? Infinity) -
        (severityRank.get(b.severity) ?? Infinity) ||
      a.page.localeCompare(b.page),
  );

  return { issues: sortedIssues, uniqueTypes: [...types].sort(), countsBySeverity };
}

function renderAudit(result) {
  const summary = document.querySelector("#summary");
  const list = document.querySelector("#issues");
  const counts = [...result.countsBySeverity]
    .map(([severity, count]) => `${severity}: ${count}`)
    .join(", ");

  summary.textContent = `${result.issues.length} open · Types: ${result.uniqueTypes.join(", ") || "none"} · ${counts || "No severity counts"}`;
  list.replaceChildren();

  result.issues.forEach((issue) => {
    const item = document.createElement("li");
    item.textContent = `[${issue.severity}] ${issue.page} / ${issue.section}: ${issue.type}`;
    list.append(item);
  });
}

renderAudit(prepareAuditQueue(audits));

// Debug checkpoint: flatMap removes one nesting level per call; the two calls
// turn pages → sections → issues into one issue array without mutating audits.
```

### React 51 App

```jsx
import { useState } from "react";

const statuses = ["backlog", "in-progress", "done"];
const initialTickets = [
  { id: 1, title: "Add empty state", status: "backlog" },
  { id: 2, title: "Fix keyboard focus", status: "in-progress" },
  { id: 3, title: "Review error copy", status: "done" },
  { id: 4, title: "Test mobile menu", status: "backlog" },
];

function TicketCard({ ticket, onMove }) {
  const statusIndex = statuses.indexOf(ticket.status);
  return (
    <article>
      <h3>{ticket.title}</h3>
      <button type="button" disabled={statusIndex === 0} onClick={() => onMove(ticket.id, -1)}>Previous</button>
      <button type="button" disabled={statusIndex === statuses.length - 1} onClick={() => onMove(ticket.id, 1)}>Next</button>
    </article>
  );
}

export default function App() {
  const [tickets, setTickets] = useState(initialTickets);

  function moveTicket(ticketId, direction) {
    setTickets((currentTickets) =>
      currentTickets.map((ticket) => {
        if (ticket.id !== ticketId) return ticket;
        const currentIndex = statuses.indexOf(ticket.status);
        const nextIndex = currentIndex + direction;
        // Ignore transitions outside the workflow boundaries.
        if (nextIndex < 0 || nextIndex >= statuses.length) return ticket;
        // Copy only the ticket whose status changes.
        return { ...ticket, status: statuses[nextIndex] };
      }),
    );
  }

  // Columns and counts are derived from the ticket source state.
  const columns = statuses.map((status) => ({
    status,
    tickets: tickets.filter((ticket) => ticket.status === status),
  }));

  return (
    <main>
      <h1>Release board</h1>
      <div className="board">
        {columns.map((column) => (
          <section key={column.status} aria-labelledby={column.status}>
            <h2 id={column.status}>{column.status} ({column.tickets.length})</h2>
            {column.tickets.length === 0 ? (
              <p>No tickets</p>
            ) : (
              column.tickets.map((ticket) => (
                <TicketCard key={ticket.id} ticket={ticket} onMove={moveTicket} />
              ))
            )}
          </section>
        ))}
      </div>
    </main>
  );
}
```

### React 52 App

```jsx
import { useState } from "react";

const initialPeople = [
  { id: 1, name: "Ava", paid: "48.00" },
  { id: 2, name: "Noah", paid: "12.00" },
  { id: 3, name: "Mia", paid: "0" },
];

function calculateSettlement(people) {
  const parsed = people.map((person) => {
    const amount = Number(person.paid);
    const isValid = Number.isFinite(amount) && amount >= 0;
    return { ...person, isValid, paidCents: isValid ? Math.round(amount * 100) : 0 };
  });

  if (parsed.some((person) => !person.isValid)) {
    return { valid: false, totalCents: 0, balances: [] };
  }

  const totalCents = parsed.reduce((sum, person) => sum + person.paidCents, 0);
  const baseShare = Math.floor(totalCents / parsed.length);
  const extraCents = totalCents % parsed.length;

  const balances = parsed.map((person, index) => {
    // Distribute leftover cents so target shares add to the exact total.
    const targetCents = baseShare + (index < extraCents ? 1 : 0);
    return { ...person, targetCents, balanceCents: person.paidCents - targetCents };
  });

  return { valid: true, totalCents, balances };
}

const money = new Intl.NumberFormat("en-GB", {
  style: "currency",
  currency: "EUR",
});

export default function App() {
  const [people, setPeople] = useState(initialPeople);
  const settlement = calculateSettlement(people);

  function updatePaid(personId, paid) {
    setPeople((currentPeople) =>
      currentPeople.map((person) =>
        person.id === personId ? { ...person, paid } : person,
      ),
    );
  }

  return (
    <main>
      <h1>Shared dinner bill</h1>
      {people.map((person) => (
        <label key={person.id}>
          {person.name}
          <input type="number" min="0" step="0.01" value={person.paid}
            onChange={(event) => updatePaid(person.id, event.target.value)} />
        </label>
      ))}

      {!settlement.valid ? (
        <p role="alert">Every payment must be a non-negative number.</p>
      ) : (
        <>
          <p>Total: {money.format(settlement.totalCents / 100)}</p>
          <ul>
            {settlement.balances.map((person) => (
              <li key={person.id}>
                {person.name}:{" "}
                {person.balanceCents === 0
                  ? "settled"
                  : person.balanceCents > 0
                    ? "should receive " + money.format(person.balanceCents / 100)
                    : "owes " + money.format(Math.abs(person.balanceCents) / 100)}
              </li>
            ))}
          </ul>
        </>
      )}
    </main>
  );
}
```
