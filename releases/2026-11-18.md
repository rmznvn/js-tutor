# Practice release — November 18, 2026

This release contains exactly three new exercises: one JavaScript exercise, one React exercise, and one comparison exercise implemented in both.

## 1. Conditions for all three exercises

### Exercise 1 — JavaScript: adjacent cinema seats

**Scenario.** Given a row of available and booked seats, find every adjacent block that fits a group of 1–4 people.

**Input.** An array of `{ id, isAvailable }` objects and a numeric group size.

**Expected behavior.** Return arrays of seat IDs; render the row and the choices; do not mutate the source array.

**Ready when.** Invalid sizes are handled, booked seats break blocks, and overlapping booking choices are included.

**Edge cases.** Decimal/zero/oversized input; no possible block; three free seats containing two overlapping two-seat blocks.

**Time.** 35–50 minutes.

### Exercise 2 — React: editable audio queue

**Scenario.** Choose, navigate, and remove tracks from a simulated audio queue.

**Input.** A fixed initial array of track objects.

**Expected behavior.** Previous/Next wrap, a non-current deletion preserves playback, and removing the current track selects a valid neighbor.

**Ready when.** Identity uses IDs, updates are immutable, and deleting the last track shows an empty state.

**Edge cases.** Navigation from either end; removing the current last track; removing the only track.

**Time.** 45–60 minutes.

### Exercise 3 — JavaScript and React: tournament bracket

**Scenario.** Choose two semifinal winners and then choose a champion from those finalists.

**Input.** Two fixed player pairs and three user choices.

**Expected behavior.** Finalists are derived; the final stays disabled until complete; changing a semifinal clears an invalid champion.

**Ready when.** Both implementations preserve the same invariant: the champion is empty or belongs to the finalist list.

**Edge cases.** One missing semifinal; a change before the final; a change after the replaced player became champion.

**Time.** 40–55 minutes per version.

## 2. Interview hints: how to reason

### Exercise 1

Ask whether overlapping blocks count, what the function should return, and how invalid sizes should behave. Inspect a fixed-size window from every valid start. Keep conversion and rendering outside the pure search function.

### Exercise 2

Ask whether navigation wraps and which neighbor replaces a removed current track. Store the editable queue and a stable current ID. Derive the current index and object. Use a functional update because removal depends on the previous queue.

### Exercise 3

Ask whether every semifinal change resets the champion or only an invalid one. Separate fixed match data, user state, and derived finalists. Validate the champion during the same transition that changes a semifinal.

## 3. Example answers spoken by the candidate

### Exercise 1

> I will include overlapping blocks because each starting position is a real booking choice. `slice` gives me a new candidate without mutation, and `every` directly expresses that all seats must be available. I will test group sizes 1, 2, 3, 0, and a value larger than the row.

### Exercise 2

> I will store a track ID instead of an index because deletion changes positions but not identity. The current object is derived. During removal, I create a new queue with `filter`; if the current item disappears, `Math.min` selects the item that moved into its position or the new last item.

### Exercise 3

> I will not store finalists because they can always be calculated from the semifinal winners. I will compute the next finalists with the new event value before validating the champion. In the DOM version I call render explicitly; in React the controlled selects render from state.

## 4. Step-by-step breakdown

### Exercise 1

1. Validate a positive integer that fits in the row.
2. Loop through starts from zero through `length - groupSize` inclusive.
3. Create each candidate with `slice` and validate it with `every`.
4. Store only the IDs of valid candidates.
5. Convert the DOM input with `Number` and format the result.

**Typical mistakes:** missing the final start with `<`; using `splice`; forgetting that input values are strings; discarding overlapping blocks.

**Manual checks:** size 2 → A1–A2, A4–A5, A5–A6; size 3 → A4–A6; size 4 → none.

**Alternative:** keep a running count of consecutive free seats. It allocates fewer temporary arrays for huge rows, while the window approach is clearer for this small UI.

### Exercise 2

1. Store `tracks` and `currentTrackId`.
2. Derive `currentIndex` and `currentTrack`.
3. Use modulo for wrapped navigation.
4. Find the removed position and create `nextTracks` with `filter`.
5. Preserve the current ID for unrelated deletion; otherwise choose a neighbor or `null`.

**Typical mistakes:** index keys; `splice`; reading beyond the new array; storing a current object that becomes stale.

**Manual checks:** last → Next → first; remove a non-current item; remove a current middle/last/only item.

**Alternative:** store the current index. It is shorter for an immutable queue but requires correction after edits, so ID state is safer here.

### Exercise 3

1. Store only semifinal winners and champion.
2. Derive finalists from semifinal winners.
3. Build a next-state view inside the semifinal transition.
4. Clear the champion only if absent from the next finalists.
5. Render final options from derived data and keep the final disabled until complete.

**Typical mistakes:** duplicated finalist state; reading a React state variable immediately after its setter; leaving an invalid selected option.

**Manual check:** Ava + Chloe → Ava champion → change Ava to Ben. The champion must clear in both implementations.

**Alternative:** always reset the champion on any semifinal change. It is simpler, but causes unnecessary resets when the selection remains valid.

### Exercise 1 — JavaScript

```js
const seats = [
  { id: "A1", isAvailable: true },
  { id: "A2", isAvailable: true },
  { id: "A3", isAvailable: false },
  { id: "A4", isAvailable: true },
  { id: "A5", isAvailable: true },
  { id: "A6", isAvailable: true },
  { id: "A7", isAvailable: false },
  { id: "A8", isAvailable: true },
];

// The function returns every valid adjacent block and does not change `seats`.
function findSeatBlocks(seatList, groupSize) {
  // Reject sizes that cannot represent a real group in this row.
  if (!Number.isInteger(groupSize) || groupSize < 1 || groupSize > seatList.length) {
    return [];
  }

  const blocks = [];

  // Stop where a full block can no longer fit in the remaining seats.
  for (let startIndex = 0; startIndex <= seatList.length - groupSize; startIndex += 1) {
    // `slice` creates a new candidate array without mutating the source row.
    const candidate = seatList.slice(startIndex, startIndex + groupSize);

    // A block is valid only when every seat inside it is available.
    const isAvailable = candidate.every((seat) => seat.isAvailable);

    if (isAvailable) {
      blocks.push(candidate.map((seat) => seat.id));
    }
  }

  return blocks;
}

function renderSeats(seatList) {
  const seatRow = document.querySelector("#seat-row");
  seatRow.innerHTML = "";

  seatList.forEach((seat) => {
    const seatElement = document.createElement("span");
    seatElement.textContent = `${seat.id} ${seat.isAvailable ? "available" : "booked"}`;
    seatElement.style.display = "inline-block";
    seatElement.style.margin = "0.25rem";
    seatElement.style.padding = "0.5rem";
    seatElement.style.background = seat.isAvailable ? "#b9f6ca" : "#ffcdd2";
    seatRow.append(seatElement);
  });
}

function showBlocks() {
  const input = document.querySelector("#group-size");
  const result = document.querySelector("#result");
  // Number converts the input string before the pure finder validates it.
  const groupSize = Number(input.value);

  if (!Number.isInteger(groupSize) || groupSize < 1 || groupSize > 4) {
    result.textContent = "Enter a whole group size from 1 to 4.";
    return;
  }

  const blocks = findSeatBlocks(seats, groupSize);

  result.textContent = blocks.length
    ? `Options: ${blocks.map((block) => block.join("–")).join(", ")}`
    : "No adjacent seats are available for this group.";
}

document.querySelector("#find-button").addEventListener("click", showBlocks);
renderSeats(seats);
showBlocks();

// These checks make the pure logic easy to verify outside the DOM.
console.assert(findSeatBlocks(seats, 2).length === 3, "Expected three two-seat blocks");
console.assert(findSeatBlocks(seats, 0).length === 0, "Invalid size must return no blocks");
```

### Exercise 2 — React

```jsx
import { useState } from "react";

const initialTracks = [
  { id: 1, title: "Northern Lights", artist: "Mira Lane" },
  { id: 2, title: "Late Train", artist: "The Signals" },
  { id: 3, title: "Paper Planes", artist: "June Atlas" },
  { id: 4, title: "Quiet City", artist: "Low Tide" },
];

export default function App() {
  // Store the queue because removing a track changes application data.
  const [tracks, setTracks] = useState(initialTracks);
  // Store a stable ID instead of an index, because indices change after deletion.
  const [currentTrackId, setCurrentTrackId] = useState(initialTracks[0].id);

  // The current index and object are derived from the two real state values.
  const currentIndex = tracks.findIndex((track) => track.id === currentTrackId);
  const currentTrack = tracks[currentIndex] ?? null;

  function playTrack(trackId) {
    setCurrentTrackId(trackId);
  }

  function playNext() {
    if (tracks.length === 0) return;

    // Wrap to the first track after the last track.
    const nextIndex = (currentIndex + 1) % tracks.length;
    setCurrentTrackId(tracks[nextIndex].id);
  }

  function playPrevious() {
    if (tracks.length === 0) return;

    // Adding the length prevents a negative modulo result at index zero.
    const previousIndex = (currentIndex - 1 + tracks.length) % tracks.length;
    setCurrentTrackId(tracks[previousIndex].id);
  }

  function removeTrack(trackId) {
    setTracks((currentTracks) => {
      const removedIndex = currentTracks.findIndex((track) => track.id === trackId);
      const nextTracks = currentTracks.filter((track) => track.id !== trackId);

      // Removing a non-current track must not interrupt the current selection.
      if (trackId !== currentTrackId) return nextTracks;

      if (nextTracks.length === 0) {
        setCurrentTrackId(null);
        return nextTracks;
      }

      // Prefer the track that moves into the removed position; for the last item,
      // the final remaining track is selected with Math.min.
      const fallbackIndex = Math.min(removedIndex, nextTracks.length - 1);
      setCurrentTrackId(nextTracks[fallbackIndex].id);
      return nextTracks;
    });
  }

  return (
    <main>
      <h1>Audio queue</h1>

      {currentTrack ? (
        <section aria-live="polite">
          <h2>Now playing: {currentTrack.title}</h2>
          <p>{currentTrack.artist}</p>
          <button onClick={playPrevious}>Previous</button>
          <button onClick={playNext}>Next</button>
        </section>
      ) : (
        <p aria-live="polite">The queue is empty.</p>
      )}

      <ul>
        {tracks.map((track) => {
          const isCurrent = track.id === currentTrackId;

          return (
            <li key={track.id}>
              <button
                onClick={() => playTrack(track.id)}
                aria-pressed={isCurrent}
              >
                {isCurrent ? "▶ " : ""}{track.title} — {track.artist}
              </button>
              <button onClick={() => removeTrack(track.id)}>
                Remove {track.title}
              </button>
            </li>
          );
        })}
      </ul>
    </main>
  );
}
```

### Exercise 3 — JavaScript

```js
const matches = {
  semi1: ["Ava", "Ben"],
  semi2: ["Chloe", "Diego"],
};

const state = {
  semi1Winner: "",
  semi2Winner: "",
  champion: "",
};

function getFinalists(bracketState) {
  // Empty semifinal winners are removed, so the final only shows valid players.
  return [bracketState.semi1Winner, bracketState.semi2Winner].filter(Boolean);
}

function updateSemifinal(bracketState, field, winner) {
  // Spread creates a new state object instead of changing the existing object.
  const nextState = { ...bracketState, [field]: winner };
  const finalists = getFinalists(nextState);

  // A former champion becomes invalid when their semifinal winner changes.
  if (!finalists.includes(nextState.champion)) {
    nextState.champion = "";
  }

  return nextState;
}

function fillSelect(select, options, placeholder) {
  select.innerHTML = "";
  const emptyOption = new Option(placeholder, "");
  select.append(emptyOption);

  options.forEach((value) => select.append(new Option(value, value)));
}

function render(bracketState) {
  const semi1Select = document.querySelector("#semi-1");
  const semi2Select = document.querySelector("#semi-2");
  const finalSelect = document.querySelector("#final");
  const summary = document.querySelector("#summary");

  fillSelect(semi1Select, matches.semi1, "Choose winner");
  fillSelect(semi2Select, matches.semi2, "Choose winner");
  fillSelect(finalSelect, getFinalists(bracketState), "Choose champion");

  semi1Select.value = bracketState.semi1Winner;
  semi2Select.value = bracketState.semi2Winner;
  finalSelect.value = bracketState.champion;
  finalSelect.disabled = getFinalists(bracketState).length < 2;

  summary.textContent = bracketState.champion
    ? `Champion: ${bracketState.champion}`
    : "Choose both semifinal winners, then choose the champion.";
}

function handleSemifinal(field, winner) {
  const nextState = updateSemifinal(state, field, winner);
  Object.assign(state, nextState);
  render(state);
}

document.querySelector("#semi-1").addEventListener("change", (event) => {
  handleSemifinal("semi1Winner", event.target.value);
});

document.querySelector("#semi-2").addEventListener("change", (event) => {
  handleSemifinal("semi2Winner", event.target.value);
});

document.querySelector("#final").addEventListener("change", (event) => {
  state.champion = event.target.value;
  render(state);
});

render(state);
```

### Exercise 3 — React

```jsx
import { useState } from "react";

const matches = {
  semi1: ["Ava", "Ben"],
  semi2: ["Chloe", "Diego"],
};

export default function App() {
  const [semi1Winner, setSemi1Winner] = useState("");
  const [semi2Winner, setSemi2Winner] = useState("");
  const [champion, setChampion] = useState("");

  // Finalists are derived from semifinal state and do not need their own state.
  const finalists = [semi1Winner, semi2Winner].filter(Boolean);

  function changeSemifinal(field, nextWinner) {
    // Update the requested semifinal while keeping the handler reusable.
    if (field === "semi1") {
      setSemi1Winner(nextWinner);
    } else {
      setSemi2Winner(nextWinner);
    }

    // Calculate the finalists after this specific change before React renders again.
    const nextFinalists = field === "semi1"
      ? [nextWinner, semi2Winner].filter(Boolean)
      : [semi1Winner, nextWinner].filter(Boolean);

    // Reset a champion that no longer belongs to the final.
    if (!nextFinalists.includes(champion)) {
      setChampion("");
    }
  }

  return (
    <main>
      <h1>Four-player tournament</h1>

      <label>
        Semifinal 1 winner
        <select
          value={semi1Winner}
          onChange={(event) => changeSemifinal("semi1", event.target.value)}
        >
          <option value="">Choose winner</option>
          {matches.semi1.map((player) => <option key={player}>{player}</option>)}
        </select>
      </label>

      <label>
        Semifinal 2 winner
        <select
          value={semi2Winner}
          onChange={(event) => changeSemifinal("semi2", event.target.value)}
        >
          <option value="">Choose winner</option>
          {matches.semi2.map((player) => <option key={player}>{player}</option>)}
        </select>
      </label>

      <label>
        Champion
        <select
          value={champion}
          disabled={finalists.length < 2}
          onChange={(event) => setChampion(event.target.value)}
        >
          <option value="">Choose champion</option>
          {finalists.map((player) => <option key={player}>{player}</option>)}
        </select>
      </label>

      <p aria-live="polite">
        {champion ? `Champion: ${champion}` : "Choose both semifinal winners, then choose the champion."}
      </p>
    </main>
  );
}
```
