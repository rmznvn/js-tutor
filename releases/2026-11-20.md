# Practice release — November 20, 2026

This release contains exactly three new exercises: one JavaScript exercise, one React exercise, and one exercise implemented in both.

## 1. Conditions for all three exercises

### Exercise 1 — JavaScript: keyboard command palette

Build a searchable command palette with wrapped Arrow Up/Down navigation, Enter selection, Escape closing, an empty state, and correct focus movement. Input data is an array of commands with labels and keywords. Search must ignore case and spaces. Estimated time: **50–65 minutes**.

Edge cases: an all-space query; filtering away the active item; pressing Enter or arrows with no results.

### Exercise 2 — React: capacity-aware room assignments

Assign attendees to rooms with fixed capacities. Occupancy and unassigned totals must be derived. Full rooms are disabled for other attendees, while a current occupant keeps their current option. Moving a person frees the old room. Estimated time: **50–65 minutes**.

Edge cases: exact capacity; a person already in a full room; moving the only occupant out of a room.

### Exercise 3 — JavaScript and React: file validation queue

Accept PDF/JPG/PNG files up to 2 MB each and 5 MB combined. Reject duplicates, preserve valid files from mixed selections, allow removal, and display errors and totals. No real upload is required. `Array.from(input.files)` converts `FileList` to a normal array. Estimated time: **50–70 minutes per implementation**.

Edge cases: mixed valid and invalid files; a batch that crosses the total limit; selecting the same file twice.

## 2. Interview hints: how to reason

### Exercise 1

Ask whether keywords participate in search, whether keyboard navigation wraps, and what execution should do. Keep filtering pure. Store open state, query, and active index; derive visible commands. Reset or guard the index whenever results change.

### Exercise 2

Ask whether unassigned attendees are allowed and whether capacity is fixed. Store attendee assignments. Derive occupancy with `reduce`. Distinguish a room that is full for another attendee from the current full room. Keep a capacity guard in the handler as well as disabled options.

### Exercise 3

Ask whether valid files from a mixed selection should be accepted and which error has priority. Validate in selection order with a running total. Return both next files and errors. Treat the `accept` attribute as guidance and still validate in code.

## 3. Example answers spoken by the candidate

### Exercise 1

> I separate the pure filter from DOM state so I can test matching independently. The active index belongs to the filtered array, so I reset it when the query changes and guard the empty result before reading an item.

### Exercise 2

> Assignments are state, but occupancy is derived data. I use `reduce` so the counts cannot drift from the attendee list. I disable a full room for other people but leave it enabled for its current occupant.

### Exercise 3

> I convert `FileList` with `Array.from`, then validate each item in order. I update the running total only after accepting a file. In React, files and the errors from the same selection live in one state object so the transition remains pure.

## 4. Step-by-step breakdown

### Exercise 1

1. Normalize the query and filter labels plus keywords.
2. Calculate visible commands from the current query.
3. Render the list and active option.
4. Reset the index after input changes.
5. Use modulo for wrapped movement.
6. Guard empty results before Enter or arrow actions.
7. Restore focus when closing.

Common mistakes: a stale out-of-range index, filtering DOM nodes instead of data, and failing to handle an empty list. Alternative: store an active command ID; it survives reordering but requires a fallback after filtering.

### Exercise 2

1. Store attendee room IDs.
2. Derive occupancy with `reduce`.
3. Render controlled selects.
4. Disable a full room only for non-occupants.
5. Guard capacity inside the update handler.
6. Update the matching attendee with `map` and spread.
7. Derive the unassigned total.

Common mistakes: mutating attendee objects, duplicated occupancy state, and relying only on disabled HTML. Alternative: keep assignments in an `{ attendeeId: roomId }` object when attendee records must stay separate.

### Exercise 3

1. Convert `FileList` to an array.
2. Copy current files and calculate their total.
3. Check duplicate, type, individual size, then combined size.
4. Update the total after each accepted file.
5. Return files and errors together.
6. Remove files immutably and reset the input after selection.
7. Derive the displayed total.

Common mistakes: trusting `accept`, identifying files only by name, and calculating the batch total only once. Alternative: reject the whole selection if any item fails; this is atomic but less convenient.

### Exercise 1 — JavaScript

```js
const commands = [
  { id: "new-note", label: "Create a note", keywords: ["add", "write"] },
  { id: "invite", label: "Invite a teammate", keywords: ["member", "email"] },
  { id: "export", label: "Export report", keywords: ["download", "csv"] },
  { id: "settings", label: "Open settings", keywords: ["preferences", "account"] },
  { id: "archive", label: "View archive", keywords: ["deleted", "old"] },
];

const paletteState = {
  isOpen: false,
  query: "",
  activeIndex: 0,
};

function filterCommands(commandList, query) {
  // Normalization makes matching independent of case and surrounding spaces.
  const normalizedQuery = query.trim().toLowerCase();

  // An empty search intentionally returns a new array with every command.
  if (!normalizedQuery) return [...commandList];

  return commandList.filter((command) => {
    // Search a single normalized string containing both the label and keywords.
    const searchableText = [command.label, ...command.keywords]
      .join(" ")
      .toLowerCase();

    return searchableText.includes(normalizedQuery);
  });
}

function getVisibleCommands() {
  return filterCommands(commands, paletteState.query);
}

function renderPalette() {
  const palette = document.querySelector("#palette");
  const input = document.querySelector("#command-search");
  const list = document.querySelector("#command-list");
  const visibleCommands = getVisibleCommands();

  palette.hidden = !paletteState.isOpen;
  input.value = paletteState.query;
  list.innerHTML = "";

  // No active option exists when the filter returns an empty array.
  if (visibleCommands.length === 0) {
    const emptyItem = document.createElement("li");
    emptyItem.textContent = "No commands found.";
    list.append(emptyItem);
    input.setAttribute("aria-activedescendant", "");
    return;
  }

  visibleCommands.forEach((command, index) => {
    const item = document.createElement("li");
    item.id = `command-${command.id}`;
    item.dataset.commandId = command.id;
    item.role = "option";
    item.textContent = command.label;
    item.setAttribute("aria-selected", String(index === paletteState.activeIndex));
    item.style.background = index === paletteState.activeIndex ? "#dbeafe" : "transparent";
    item.style.padding = "0.5rem";
    list.append(item);
  });

  input.setAttribute(
    "aria-activedescendant",
    `command-${visibleCommands[paletteState.activeIndex].id}`
  );
}

function openPalette() {
  paletteState.isOpen = true;
  paletteState.query = "";
  paletteState.activeIndex = 0;
  renderPalette();
  document.querySelector("#command-search").focus();
}

function closePalette() {
  paletteState.isOpen = false;
  renderPalette();
  // Return focus to the control that opened the temporary interface.
  document.querySelector("#open-palette").focus();
}

function executeCommand(command) {
  document.querySelector("#status").textContent = `Executed: ${command.label}`;
  closePalette();
}

function moveActiveIndex(direction) {
  const visibleCommands = getVisibleCommands();
  if (visibleCommands.length === 0) return;

  // Adding the length keeps the result positive when moving above index zero.
  paletteState.activeIndex =
    (paletteState.activeIndex + direction + visibleCommands.length) %
    visibleCommands.length;

  renderPalette();
}

document.querySelector("#open-palette").addEventListener("click", openPalette);

document.querySelector("#command-search").addEventListener("input", (event) => {
  paletteState.query = event.target.value;
  // A new result list starts from its first item.
  paletteState.activeIndex = 0;
  renderPalette();
});

document.querySelector("#command-search").addEventListener("keydown", (event) => {
  if (event.key === "ArrowDown") {
    event.preventDefault();
    moveActiveIndex(1);
  } else if (event.key === "ArrowUp") {
    event.preventDefault();
    moveActiveIndex(-1);
  } else if (event.key === "Enter") {
    event.preventDefault();
    const command = getVisibleCommands()[paletteState.activeIndex];
    if (command) executeCommand(command);
  } else if (event.key === "Escape") {
    closePalette();
  }
});

document.querySelector("#command-list").addEventListener("click", (event) => {
  const item = event.target.closest("[data-command-id]");
  if (!item) return;

  const command = commands.find(({ id }) => id === item.dataset.commandId);
  if (command) executeCommand(command);
});

renderPalette();
```

### Exercise 2 — React

```jsx
import { useState } from "react";

const rooms = [
  { id: "maple", name: "Maple Room", capacity: 2 },
  { id: "cedar", name: "Cedar Room", capacity: 1 },
  { id: "oak", name: "Oak Room", capacity: 2 },
];

const initialAttendees = [
  { id: 1, name: "Amina", roomId: null },
  { id: 2, name: "Jon", roomId: null },
  { id: 3, name: "Lena", roomId: null },
  { id: 4, name: "Marco", roomId: null },
];

export default function App() {
  // Each attendee stores only the selected room ID; room details remain fixed data.
  const [attendees, setAttendees] = useState(initialAttendees);
  const [message, setMessage] = useState("Assign each attendee to a room.");

  // Occupancy is derived from attendees, so it cannot become stale independently.
  const occupancy = attendees.reduce((counts, attendee) => {
    if (attendee.roomId) {
      counts[attendee.roomId] = (counts[attendee.roomId] ?? 0) + 1;
    }
    return counts;
  }, {});

  function assignRoom(attendeeId, nextRoomId) {
    const attendee = attendees.find(({ id }) => id === attendeeId);
    const room = rooms.find(({ id }) => id === nextRoomId);

    // An empty value means “unassigned” and does not need a capacity check.
    if (room && attendee?.roomId !== nextRoomId) {
      const currentOccupancy = occupancy[nextRoomId] ?? 0;

      // Keep this guard even though full options are disabled in the interface.
      if (currentOccupancy >= room.capacity) {
        setMessage(`${room.name} is already full.`);
        return;
      }
    }

    setAttendees((currentAttendees) =>
      currentAttendees.map((currentAttendee) =>
        currentAttendee.id === attendeeId
          ? { ...currentAttendee, roomId: nextRoomId || null }
          : currentAttendee
      )
    );

    setMessage(nextRoomId ? "Assignment updated." : "Attendee is now unassigned.");
  }

  const unassignedCount = attendees.filter(({ roomId }) => !roomId).length;

  return (
    <main>
      <h1>Workshop room assignments</h1>

      <section aria-label="Room occupancy">
        <h2>Occupancy</h2>
        <ul>
          {rooms.map((room) => (
            <li key={room.id}>
              {room.name}: {occupancy[room.id] ?? 0}/{room.capacity}
            </li>
          ))}
        </ul>
      </section>

      <section>
        <h2>Attendees</h2>
        {attendees.map((attendee) => (
          <label key={attendee.id}>
            {attendee.name}
            <select
              value={attendee.roomId ?? ""}
              onChange={(event) => assignRoom(attendee.id, event.target.value)}
            >
              <option value="">Unassigned</option>
              {rooms.map((room) => {
                const isCurrentRoom = attendee.roomId === room.id;
                const isFull = (occupancy[room.id] ?? 0) >= room.capacity;

                return (
                  <option
                    key={room.id}
                    value={room.id}
                    disabled={isFull && !isCurrentRoom}
                  >
                    {room.name} ({occupancy[room.id] ?? 0}/{room.capacity})
                  </option>
                );
              })}
            </select>
          </label>
        ))}
      </section>

      <p>{unassignedCount} attendee(s) still unassigned.</p>
      <p aria-live="polite">{message}</p>
    </main>
  );
}
```

### Exercise 3 — JavaScript

```js
const MAX_FILE_SIZE = 2 * 1024 * 1024;
const MAX_TOTAL_SIZE = 5 * 1024 * 1024;
const ALLOWED_TYPES = ["application/pdf", "image/jpeg", "image/png"];

let acceptedFiles = [];
let validationErrors = [];

function getFileId(file) {
  // The combination distinguishes files better than the name alone.
  return `${file.name}-${file.size}-${file.lastModified ?? 0}`;
}

function addFiles(currentFiles, incomingFiles) {
  const nextFiles = [...currentFiles];
  const errors = [];
  let totalSize = nextFiles.reduce((sum, file) => sum + file.size, 0);

  incomingFiles.forEach((file) => {
    const isDuplicate = nextFiles.some(
      (currentFile) => getFileId(currentFile) === getFileId(file)
    );

    if (isDuplicate) {
      errors.push(`${file.name}: this file is already in the queue.`);
      return;
    }

    if (!ALLOWED_TYPES.includes(file.type)) {
      errors.push(`${file.name}: unsupported file type.`);
      return;
    }

    if (file.size > MAX_FILE_SIZE) {
      errors.push(`${file.name}: the file is larger than 2 MB.`);
      return;
    }

    if (totalSize + file.size > MAX_TOTAL_SIZE) {
      errors.push(`${file.name}: adding it would exceed the 5 MB total.`);
      return;
    }

    nextFiles.push(file);
    totalSize += file.size;
  });

  return { files: nextFiles, errors };
}

function formatMegabytes(bytes) {
  return (bytes / 1024 / 1024).toFixed(2);
}

function render() {
  const fileList = document.querySelector("#file-list");
  const errorList = document.querySelector("#error-list");
  const summary = document.querySelector("#summary");

  fileList.innerHTML = "";
  errorList.innerHTML = "";

  acceptedFiles.forEach((file) => {
    const item = document.createElement("li");
    const button = document.createElement("button");
    button.type = "button";
    button.dataset.fileId = getFileId(file);
    button.textContent = `Remove ${file.name}`;
    item.append(`${file.name} — ${formatMegabytes(file.size)} MB `, button);
    fileList.append(item);
  });

  validationErrors.forEach((error) => {
    const item = document.createElement("li");
    item.textContent = error;
    errorList.append(item);
  });

  const totalSize = acceptedFiles.reduce((sum, file) => sum + file.size, 0);
  summary.textContent = `${acceptedFiles.length} file(s), ${formatMegabytes(totalSize)} MB total.`;
}

document.querySelector("#file-input").addEventListener("change", (event) => {
  // FileList is array-like; Array.from provides array methods and predictable iteration.
  const incomingFiles = Array.from(event.target.files);
  const result = addFiles(acceptedFiles, incomingFiles);

  acceptedFiles = result.files;
  validationErrors = result.errors;

  // Resetting allows the same file to trigger change again after removal.
  event.target.value = "";
  render();
});

document.querySelector("#file-list").addEventListener("click", (event) => {
  const button = event.target.closest("[data-file-id]");
  if (!button) return;

  acceptedFiles = acceptedFiles.filter(
    (file) => getFileId(file) !== button.dataset.fileId
  );
  validationErrors = [];
  render();
});

render();
```

### Exercise 3 — React

```jsx
import { useState } from "react";

const MAX_FILE_SIZE = 2 * 1024 * 1024;
const MAX_TOTAL_SIZE = 5 * 1024 * 1024;
const ALLOWED_TYPES = ["application/pdf", "image/jpeg", "image/png"];

function getFileId(file) {
  // A combined ID is more reliable than a file name by itself.
  return `${file.name}-${file.size}-${file.lastModified ?? 0}`;
}

function validateAndAddFiles(currentFiles, incomingFiles) {
  const nextFiles = [...currentFiles];
  const errors = [];
  let totalSize = nextFiles.reduce((sum, file) => sum + file.size, 0);

  incomingFiles.forEach((file) => {
    const isDuplicate = nextFiles.some(
      (currentFile) => getFileId(currentFile) === getFileId(file)
    );

    if (isDuplicate) {
      errors.push(`${file.name}: this file is already in the queue.`);
    } else if (!ALLOWED_TYPES.includes(file.type)) {
      errors.push(`${file.name}: unsupported file type.`);
    } else if (file.size > MAX_FILE_SIZE) {
      errors.push(`${file.name}: the file is larger than 2 MB.`);
    } else if (totalSize + file.size > MAX_TOTAL_SIZE) {
      errors.push(`${file.name}: adding it would exceed the 5 MB total.`);
    } else {
      nextFiles.push(file);
      totalSize += file.size;
    }
  });

  return { files: nextFiles, errors };
}

function formatMegabytes(bytes) {
  return (bytes / 1024 / 1024).toFixed(2);
}

export default function App() {
  // Files and the errors produced by the same selection are updated together.
  const [queue, setQueue] = useState({ files: [], errors: [] });
  const { files, errors } = queue;

  function handleFiles(event) {
    // Convert FileList so the validation function receives a normal array.
    const incomingFiles = Array.from(event.target.files);

    setQueue((currentQueue) =>
      validateAndAddFiles(currentQueue.files, incomingFiles)
    );

    // Permit selecting the same file again after it has been removed.
    event.target.value = "";
  }

  function removeFile(fileId) {
    setQueue((currentQueue) => ({
      files: currentQueue.files.filter(
        (file) => getFileId(file) !== fileId
      ),
      errors: [],
    }));
  }

  // The total is derived from the accepted files and needs no separate state.
  const totalSize = files.reduce((sum, file) => sum + file.size, 0);

  return (
    <main>
      <h1>Attach application documents</h1>
      <p>PDF, JPG, or PNG. Maximum 2 MB per file and 5 MB in total.</p>

      <input
        type="file"
        multiple
        accept=".pdf,.jpg,.jpeg,.png"
        onChange={handleFiles}
      />

      <ul>
        {files.map((file) => {
          const fileId = getFileId(file);

          return (
            <li key={fileId}>
              {file.name} — {formatMegabytes(file.size)} MB
              <button type="button" onClick={() => removeFile(fileId)}>
                Remove {file.name}
              </button>
            </li>
          );
        })}
      </ul>

      <ul aria-live="polite">
        {errors.map((error) => <li key={error}>{error}</li>)}
      </ul>

      <p>{files.length} file(s), {formatMegabytes(totalSize)} MB total.</p>
    </main>
  );
}
```
