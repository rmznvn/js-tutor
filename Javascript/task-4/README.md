# Подготовка данных для пагинации — JavaScript

Материал из выпуска **2026-10-05**. Время: **20–25 минут**.

## Условие

Медиатека показывает карточки по нескольку на странице.

### Критерии готовности

- paginate(items, page, pageSize) возвращает items, currentPage, totalPages.
- Страницы с 1, индексы массива с 0.
- Номер ниже диапазона становится 1, выше — последней страницей.
- Для пустого массива items=[], currentPage=1, totalPages=0.
- page целый; pageSize положительный целый; исходный массив не меняется.

### Ожидаемое поведение

| page при pageSize=2 | ID | currentPage | totalPages |
|---|---|---:|---:|
| 1 | 1, 2 | 1 | 3 |
| 2 | 3, 4 | 2 | 3 |
| 99 | 5 | 3 | 3 |
| 0 | 1, 2 | 1 | 3 |

### Крайние случаи

- Пустой массив.
- Неполная последняя страница.
- Номер за пределами диапазона.

## Как рассуждать

1. **Интервьюер:** «Как считать неполную страницу?»

2. **Интервьюер:** «Как получить начало диапазона?»

3. **Интервьюер:** «slice или splice?»

Определи вход, результат и ограничения. Разбей действие на преобразование данных и отображение. Перед написанием кода предскажи результат на маленьком примере.

## Как отвечать на собеседовании

> «Применю Math.ceil к items.length/pageSize: дробная часть требует ещё одной страницы.»

> «Начало равно (currentPage - 1) * pageSize. Сначала ограничу номер допустимым диапазоном.»

> «slice создаёт новый массив и не включает конечный индекс. splice меняет исходный массив, что нарушает условие.»

## Пошаговый разбор

1. Вычислить totalPages с округлением вверх.
2. Отдельно обработать пустой список.
3. Ограничить номер через Math.min и Math.max.
4. Вычислить начальный индекс.
5. Взять slice(start, start + pageSize).
6. Вернуть данные и метаданные.

## Типичные ошибки

- Округление вниз теряет последнюю страницу.
- page * pageSize пропускает первую страницу.
- splice удаляет элементы входного массива.

## Альтернативный способ

filter с проверкой диапазона индексов тоже работает, но проходит по всему массиву. slice яснее выражает получение непрерывного участка.

```js
const articles = [
  { id: 1, title: "BIM-модели" },
  { id: 2, title: "Общие данные" },
  { id: 3, title: "Планирование" },
  { id: 4, title: "Проверка документов" },
  { id: 5, title: "AI в строительстве" },
];

function paginate(items, page, pageSize) {
  // Предусловия: page целый, pageSize — положительный целый.
  // Округляем вверх: неполная последняя страница тоже считается.
  const totalPages = Math.ceil(items.length / pageSize);
  // У пустого массива нет страниц; currentPage по условию равен 1.
  if (totalPages === 0) {
    return { items: [], currentPage: 1, totalPages: 0 };
  }
  // Ограничиваем номер сверху последней страницей и снизу единицей.
  const currentPage = Math.max(1, Math.min(page, totalPages));
  // Страницы начинаются с 1, индексы массива — с 0.
  const startIndex = (currentPage - 1) * pageSize;
  // Конечный индекс slice не включается; исходный массив сохраняется.
  const pageItems = items.slice(startIndex, startIndex + pageSize);
  return { items: pageItems, currentPage, totalPages };
}

// Альтернатива: filter получает индекс вторым аргументом.
// Выбираем элементы в том же полуоткрытом диапазоне [start, end).
function paginateWithFilter(items, page, pageSize) {
  const totalPages = Math.ceil(items.length / pageSize);
  if (totalPages === 0) return { items: [], currentPage: 1, totalPages: 0 };
  const currentPage = Math.max(1, Math.min(page, totalPages));
  const start = (currentPage - 1) * pageSize;
  return {
    items: items.filter((item, index) => index >= start && index < start + pageSize),
    currentPage,
    totalPages,
  };
}
console.log("Страница 2:", paginate(articles, 2, 2));
console.log("Страница 99:", paginate(articles, 99, 2));
console.log("Страница 0:", paginate(articles, 0, 2));
console.log("Пустой массив:", paginate([], 1, 2));
```
