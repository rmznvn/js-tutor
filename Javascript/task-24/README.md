# Подготовка карточек из неполных данных — JavaScript

Выпуск **2026-10-28**. Время: 25–35 минут.

## Условие

Данные материалов приходят с незаполненными полями. Подготовь единый формат карточки для отображения.

### Входные данные и критерии готовности

- Чистая prepareCards(items) возвращает новые объекты {id,title,authorName,price,priceLabel}.
- title и author.name — строка/null/отсутствует; pricing.amount — число >=0/null/отсутствует. Проверять произвольные неверные типы не требуется.
- Пробельное или отсутствующее название → «Без названия»; имя → «Автор не указан».
- Цена 0 → «Бесплатно»; отсутствующая → price:null и «Цена не указана»; положительная → число + ₽.
- Входные объекты не меняются; ?. защищает отсутствующие вложенные поля, ?? сохраняет 0.

### Крайние случаи

- Нулевая цена.
- author:null, pricing:null или отсутствующие поля.
- Пробельные строки; пустой массив.

## Как рассуждать

- Чем ноль отличается от отсутствующей цены?
- Где выбрать ??, а где ||?
- Зачем нормализовать данные до рендера?

Сначала предскажи результат одного действия на маленьком примере. Раздели входные данные, состояние и вычисляемые значения. Выбери метод после определения нужного преобразования.

## Примеры ответов вслух

> «Ноль — допустимое значение и означает бесплатный материал. Отсутствующую цену обозначу null, поэтому не подставлю платную/неизвестную цену вместо нуля.»

> «Для цены использую ??, он срабатывает только на null/undefined. Для строки после trim использую ||: пустая строка тоже требует подстановки.»

> «map создаст новые объекты с едиными полями. Разметке не придётся повторять проверки вложенных данных. Проверю 0, null, пробелы и неизменность исходных объектов.»

## Пошаговый разбор

1. Обойти исходные элементы через map.
2. Прочитать pricing?.amount и применить ?? null.
3. Нормализовать строки trim и подставить текст для пустоты.
4. Отдельно различить price===null, price===0 и положительное число.
5. Вернуть новый объект с ID.
6. Проверить отсутствие мутаций.

## Типичные ошибки

- amount || null теряет бесплатную цену 0.
- author.name без ?. падает при author:null.
- trim без проверки отсутствующей строки.
- Изменять поля входного item.

## Альтернативный способ

Нормализовать поля прямо при рендере можно для одной маленькой карточки; проверки дублируются в других компонентах. Чистая функция удобнее для повторного использования и независимой проверки.

## Ручная проверка

ID1: React, Анна, price0, Бесплатно. ID2: Без названия, Автор не указан, 1500 ₽. ID3: null и Цена не указана. ID4: Автор не указан. Исходный title у ID1 остаётся с пробелами.

## Запуск

Открой index.html. Примеры чистой функции находятся в DevTools → Console.

### script.js

```js
const rawCards = [
  { id: 1, title: " React ", pricing: { amount: 0 }, author: { name: "Анна" } },
  { id: 2, title: "", pricing: { amount: 1500 }, author: null },
  { id: 3, pricing: null },
  { id: 4, title: "DOM", pricing: { amount: 2500 }, author: { name: " " } },
];

function prepareCards(items) {
  return items.map((item) => {
    // Контракт: title/name — строка или отсутствует; amount — число >= 0 или null.
    // ?. допускает отсутствие промежуточных объектов.
    // ?? сохраняет допустимый 0, подставляя null только для null/undefined.
    const price = item.pricing?.amount ?? null;

    return {
      id: item.id,
      // После trim пустая строка тоже требует подстановки, поэтому используем ||.
      title: item.title?.trim() || "Без названия",
      authorName: item.author?.name?.trim() || "Автор не указан",
      price,
      // null означает неизвестную цену, 0 — бесплатный материал.
      priceLabel: price === null ? "Цена не указана" :
        price === 0 ? "Бесплатно" : price + " ₽",
    };
  });
}

// Новые объекты готовы для карточек; rawCards и вложенные объекты не меняются.
console.log(prepareCards(rawCards));
console.log(prepareCards([])); // Пустой вход даёт пустой результат.

```
