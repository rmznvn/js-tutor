# Сортировка тарифов без изменения исходных данных — JavaScript

Материал из выпуска **2026-10-02**. Время: **15–20 минут**.

## Условие

На странице тарифов пользователь выбирает сортировку по цене.

### Критерии готовности

- Функция sortPlans(plans, direction) возвращает новый массив.
- asc — цена по возрастанию, desc — по убыванию.
- При равной цене названия идут по алфавиту в обоих режимах.
- Исходный массив сохраняет порядок. Цены — корректные числа; direction — asc или desc.

### Ожидаемое поведение

| Направление | Порядок ID |
|---|---|
| asc | 4, 2, 3, 1 |
| desc | 3, 1, 2, 4 |

### Крайние случаи

- Пустой массив.
- Цена 0.
- Одинаковые цены.

## Как рассуждать

1. **Интервьюер:** «Что изменяет sort() и как сохранить входной массив?»

2. **Интервьюер:** «Как сортировать сразу по двум критериям?»

3. **Интервьюер:** «Почему reverse() результата asc не подходит для desc?»

Определи вход, результат и ограничения. Разбей действие на преобразование данных и отображение. Перед написанием кода предскажи результат на маленьком примере.

## Как отвечать на собеседовании

> «Я создам копию массива через spread, затем вызову sort на копии. Объекты не меняются, поэтому поверхностной копии достаточно.»

> «Сначала сравню цены и учту направление. При равенстве сравню названия через localeCompare с локалью ru.»

> «reverse перевернёт и названия внутри группы одинаковой цены, а по условию там нужен алфавитный порядок в обоих режимах.»

## Пошаговый разбор

1. Скопировать массив через [...plans].
2. В компараторе вычислить a.price - b.price.
3. При отличающихся ценах вернуть разницу либо её отрицание.
4. При равенстве вернуть сравнение названий через localeCompare.
5. Вывести оба результата и проверить исходный порядок.

## Типичные ошибки

- sort(plans) без копии меняет вход.
- Boolean в компараторе не задаёт нужный трёхсторонний порядок.
- reverse() ломает второй критерий.

## Альтернативный способ

Сначала сгруппировать по цене, отсортировать цены и названия каждой группы, затем объединить. Полезно для интерфейса с ценовыми группами; для плоского списка сложнее одного компаратора.

## Проверка

Сопоставь результаты с таблицей выше и проверь каждый крайний случай. Для неизменяемых обновлений дополнительно проверь сохранение исходных данных и отсутствие влияния на соседние элементы.

## Запуск

Открой `index.html` в браузере. Для задач на данные смотри DevTools → Console. Файл `script.js` содержит эталонное решение; для самостоятельной попытки сначала прочитай условие и создай свой файл.

```js
// Тарифы сортируем по цене, при равенстве — по названию.
const plans = [
  { id: 1, title: "Команда", price: 3000 },
  { id: 2, title: "Базовый", price: 1000 },
  { id: 3, title: "Бизнес", price: 3000 },
  { id: 4, title: "Демо", price: 0 },
];

function sortPlans(plans, direction) {
  // sort меняет массив, поэтому сначала создаём поверхностную копию.
  // Объекты не копируем: меняется только порядок, а не их поля.
  return [...plans].sort((a, b) => {
    const priceDifference = a.price - b.price;
    // Отрицательное число ставит a раньше b; положительное — позже.
    if (priceDifference !== 0) {
      return direction === "asc" ? priceDifference : -priceDifference;
    }
    // При равных ценах алфавитный порядок сохраняется в обоих режимах.
    return a.title.localeCompare(b.title, "ru");
  });
}

// Альтернатива: сначала группируем тарифы по цене.
// Полезна, когда интерфейс тоже показывает отдельные ценовые группы.
function sortPlansByGroups(plans, direction) {
  const groups = plans.reduce((result, plan) => {
    // Ключ — цена, значение — новый локальный массив группы.
    if (!result[plan.price]) result[plan.price] = [];
    result[plan.price].push(plan);
    return result;
  }, {});
  const prices = Object.keys(groups).map(Number).sort(
    (a, b) => direction === "asc" ? a - b : b - a
  );
  // Группы локальные: их сортировка не меняет входной массив.
  return prices.reduce((result, price) => {
    const group = groups[price].sort(
      (a, b) => a.title.localeCompare(b.title, "ru")
    );
    return [...result, ...group];
  }, []);
}

console.log("asc:", sortPlans(plans, "asc").map((plan) => plan.id));
console.log("desc:", sortPlans(plans, "desc").map((plan) => plan.id));
console.log("Исходный порядок:", plans.map((plan) => plan.id));
```
