# FAQ с одним открытым ответом — JavaScript

Материал из выпуска **2026-10-02**. Время: **35–45 минут на обе версии**.

## Условие

Пользователь раскрывает ответы на вопросы; одновременно открыт максимум один.

### Критерии готовности

- Изначально все ответы закрыты.
- Первый клик открывает, повторный закрывает; другой вопрос заменяет открытый.
- Хранится openId, null означает отсутствие открытого вопроса.
- Кнопки имеют aria-expanded и aria-controls; ответ скрывается через hidden.
- Реализации на DOM и React; анимация не требуется.

### Ожидаемое поведение

| Действие | Открытый ID |
|---|---|
| Начало | null |
| Первый вопрос | 0 |
| Второй вопрос | 1 |
| Второй ещё раз | null |

### Крайние случаи

- ID 0 допустим.
- Повторный клик закрывает.
- Переключение закрывает предыдущий.

## Как рассуждать

1. **Интервьюер:** «Нужен ли boolean для каждого вопроса?»

2. **Интервьюер:** «Чем обозначить отсутствие открытого пункта?»

3. **Интервьюер:** «Что общего у JS и React?»

Определи вход, результат и ограничения. Разбей действие на преобразование данных и отображение. Перед написанием кода предскажи результат на маленьком примере.

## Как отвечать на собеседовании

> «Достаточно одного openId: он не позволяет одновременно открыть два ответа.»

> «Использую null. Проверяю равенство ID, а не truthy: число 0 тоже ID.»

> «Правило перехода одно: совпадение закрывает, другой ID открывает. В JS вызываю render и обновляю DOM; React обновляет JSX после setState.»

## Пошаговый разбор

1. Объявить openId = null.
2. На клике сравнить текущий и нажатый ID.
3. Выбрать null либо новый ID.
4. Для каждого вопроса вычислить isOpen.
5. Обновить aria-expanded и hidden.
6. В React использовать функциональное обновление openId.

## Типичные ошибки

- if(openId) неверно трактует числовой 0.
- dataset возвращает строки: в DOM сравниваем одинаковые типы.
- Несколько независимых boolean усложняют единственное открытие.

## Альтернативный способ

## Полное решение с комментариями

Рабочий файл: [script.js](script.js). Код помещён в конце, чтобы можно было сначала решить задачу самостоятельно.

<summary>Показать полный код</summary>

```js
// ID из dataset — строки. null отдельно означает «всё закрыто».
const items = document.querySelectorAll("#faq [data-faq-item]");
let openId = null;

function render() {
  items.forEach((item) => {
    const isOpen = item.dataset.id === openId;
    const button = item.querySelector("button");
    // aria-controls содержит ID связанного ответа.
    const answer = document.getElementById(button.getAttribute("aria-controls"));
    button.setAttribute("aria-expanded", String(isOpen));
    answer.hidden = !isOpen;
  });
}
items.forEach((item) => {
  item.querySelector("button").addEventListener("click", () => {
    const id = item.dataset.id;
    // Повторный клик закрывает ответ, другой клик заменяет открытый ID.
    // Не используем if(openId): числовой ID 0 тоже может быть допустимым.
    openId = openId === id ? null : id;
    render();
  });
});
render();
```
