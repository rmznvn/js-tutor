# JavaScript: объединение статей CMS без дубликатов
Выпуск: 4 ноября 2026.

## Условие
Сайт уже показывает статьи; приходит новая порция данных CMS.
Текущие: {id:1,title:"Основы CMS",published:false}, {id:2,title:"React: черновик",published:false}.
Входящие по порядку: {id:2,title:"React: состояние",published:true}, {id:3,title:"События DOM",published:false}, {id:2,title:"React: обновлённая статья",published:false}.
Напиши mergeArticles(current, incoming). Совпавший ID полностью заменяет старую запись на прежнем месте; новые ID добавляются в конец. Последняя входящая версия ID побеждает; позиция определяется первым появлением ID.
Контракт: в current ID уникальны; incoming может содержать повторы; все записи полные, плоские; ID числовые.
Готово: результат 1,2,3; у ID2 последнее название и published:false; входные массивы и объекты не меняются, объекты результата — новые.
Крайние случаи: обновление индекса 0; повтор ID во входящих; один или оба массива пусты.
Время: 20–30 минут.

## Как рассуждать
1. Обновление — полная замена или частичный patch?
2. Можно ли менять созданный внутри функции массив?
3. Как отличить найденный индекс 0 от отсутствия?

## Примеры ответов вслух
«По контракту входящие записи полные. Поэтому заменю объект целиком, а не буду сливать поля: старая версия не должна сохранять лишние данные».
«Создам новый массив и копии плоских объектов. Затем могу менять свой локальный результат через push и присваивание по индексу: входные данные это не затрагивает».
«findIndex вернёт -1 при отсутствии. Проверю именно index === -1, потому что 0 — допустимая найденная позиция. Последовательный обход позволит последней версии победить».
«Проверю порядок 1,2,3, published:false последней версии, пустые массивы и отсутствие общих объектов результата со входом».

## Пошаговый разбор
1. Скопируй current через map со spread каждого объекта.
2. Обойди incoming по порядку.
3. Найди ID в текущем результате.
4. Отсутствующий добавь, существующий замени на его позиции.
5. Копируй входящую запись перед сохранением.
6. Верни результат.

Ошибки: if(index) неверно различает 0 и -1; копировать только массив; добавлять каждый входящий объект в конец; частично сливать поля вместо согласованной полной замены.
Проверки: основной пример → 1,2,3 и последняя версия ID2; обновить ID1 → он остаётся первым; []+incoming → уникальные 2,3 с последней версией ID2; current+[] → копии; []+[] → [].
Альтернатива: Map с ID как ключом. set заменяет данные, сохраняя позицию уже существующего ключа. Подходит большим наборам: поиск по ключу обычно эффективнее повторного findIndex. Но это новая коллекция; для небольшого учебного массива знакомый findIndex проще. Наш вариант при росте обоих массивов может потребовать квадратичное число сравнений.

## Запуск
Открой index.html и консоль. Функция не зависит от DOM.

### script.js

```js
const currentArticles = [
  { id: 1, title: "Основы CMS", published: false },
  { id: 2, title: "React: черновик", published: false },
];
const incomingArticles = [
  { id: 2, title: "React: состояние", published: true },
  { id: 3, title: "События DOM", published: false },
  { id: 2, title: "React: обновлённая статья", published: false },
];

function mergeArticles(current, incoming) {
  // Копируем массив и каждый плоский объект.
  // Последующие изменения результата не затронут входные объекты.
  const result = current.map((article) => ({ ...article }));

  incoming.forEach((article) => {
    const index = result.findIndex((item) => item.id === article.id);
    // Создаём копию и для входящих записей.
    const copy = { ...article };

    // Нельзя проверять if(index): 0 — найденный индекс, -1 — отсутствие.
    if (index === -1) {
      result.push(copy); // Новый ID добавляется в конец.
    } else {
      // Последняя входящая версия побеждает целиком.
      // Замена на прежней позиции сохраняет порядок.
      result[index] = copy;
    }
  });

  // Мутировался только созданный внутри функции result.
  return result;
}

// Порядок: 1, 2, 3; для ID 2 берётся последняя версия.
console.log(mergeArticles(currentArticles, incomingArticles));
// При пустом обновлении возвращаются копии исходных записей.
console.log(mergeArticles(currentArticles, []));
// Исходные массивы и объекты не изменены.
console.log(currentArticles, incomingArticles);
```
