# JavaScript: свободные интервалы бронирования

Выпуск за понедельник 16 ноября 2026. Добавлен 17 ноября как пропущенный выпуск. Уровень: Junior+.

## Условие
На странице записи на консультацию нужно скрыть занятые интервалы. Вход: slots с ID 1–4, интервалами 600–630, 630–660, 660–690, 690–720 минут; bookings = [{start:630,end:660}]; минимальная длительность выбирается из 30/45 минут. Все интервалы валидные, целые, внутри одного дня; start < end. Они полуоткрытые [start,end): касание границ не считается пересечением. Покажи подходящие слоты по возрастанию начала, счётчик и пустое состояние. Слоты не объединяем: ищем отдельный готовый интервал. Для 30 минут ожидаются ID 1,3,4; для 45 — пусто. Критерии: чистая getAvailableSlots, исходные массивы и объекты не меняются. Время: 25–35 минут. Крайние случаи: пустые bookings; пересечение на одну минуту; слот ровно нужной длины.

## Как рассуждать — вопросы интервьюера
1. Как понять, пересекаются ли два интервала?
2. Почему sort здесь не мутирует исходные слоты?
3. Какие входные данные нужно уточнить у интервьюера?

## Примеры ответов вслух
«Уточню, разрешены ли соседние интервалы. Для [start,end) пересечение есть, если начало каждого раньше конца другого. Применю два строгих сравнения через &&»

«Сначала filter создаёт новый массив. sort меняет этот новый массив. Объекты разделяются по ссылке, но я их не изменяю»

«Уточню единицы времени, переход через полночь и валидность диапазонов. Здесь минуты одного дня уже проверены, поэтому не добавляю парсер дат. Проверю касание, частичное и полное перекрытие»

## Пошаговый разбор
1. Отдели чистую обработку интервалов от DOM.
2. Для слота проверь длительность через >=.
3. Через some найди хотя бы одну конфликтующую бронь. Для пустого busy some вернёт false.
4. Оставь достаточно длинный слот без конфликта, затем отсортируй новый массив.
5. Преобразуй минуты в подписи времени; обнови список и сообщение из одного результата.

Типичные ошибки: Использовать <= и запрещать соседей; отсортировать slots до filter; оставить строку minDuration; объединять соседние слоты, хотя этого не требуется.

Ручные проверки: 30 → 1/3/4; 45 → 0. busy=[] → все четыре. Бронь 629–631 исключает 1 и 2. Бронь 630–660 не исключает соседей 1/3. До и после вызова сравни исходные данные.

Альтернатива: Вместо some — цикл по броням с ранним выходом при пересечении. Проще отлаживать по шагам; some короче передаёт условие «хотя бы одна». При больших объёмах нужен отдельный подход к индексированию интервалов, но для этой задачи он избыточен.

### script.js

```js
// Интервалы заданы минутами от начала дня: 600 = 10:00.
const slots = [
  { id: 1, start: 600, end: 630 },
  { id: 2, start: 630, end: 660 },
  { id: 3, start: 660, end: 690 },
  { id: 4, start: 690, end: 720 },
];
const bookings = [{ start: 630, end: 660 }];

function getAvailableSlots(items, busy, minDuration) {
  // filter создаёт новый массив; исходные интервалы остаются неизменными.
  return items.filter((slot) => {
    // Ровно нужная длительность подходит: используем >=, а не >.
    const longEnough = slot.end - slot.start >= minDuration;
    // some отвечает на вопрос «есть хотя бы одно пересечение?».
    // Строгие сравнения разрешают соседние интервалы: [600,630) и [630,660).
    const overlaps = busy.some((booking) =>
      slot.start < booking.end && booking.start < slot.end
    );
    // Оставляем только достаточно длинные слоты без пересечений.
    return longEnough && !overlaps;
  }).sort((a, b) => a.start - b.start); // Сортируем результат filter, не items.
}

function formatTime(minutes) {
  // Целая часть — часы, остаток — минуты; padStart добавляет ведущий ноль.
  return String(Math.floor(minutes / 60)).padStart(2, "0") + ":" +
    String(minutes % 60).padStart(2, "0");
}

const input = document.getElementById("duration");
const list = document.getElementById("slots");
const message = document.getElementById("message");
function render() {
  // value у select — строка. Преобразуем её перед числовым сравнением.
  const visible = getAvailableSlots(slots, bookings, Number(input.value));
  list.replaceChildren();
  message.textContent = visible.length ? "Свободных слотов: " + visible.length : "Нет подходящих слотов";
  visible.forEach((slot) => {
    const li = document.createElement("li");
    // Данные выводим текстом: HTML из названий сюда не подставляется.
    li.textContent = formatTime(slot.start) + "–" + formatTime(slot.end);
    list.append(li);
  });
}
input.addEventListener("change", render);
render();
```
