# Живые проверки пароля — JavaScript

Материал из выпуска **2026-10-05**. Время: **30–45 минут на обе версии**.

## Условие

Под полем отображаются требования с ✓ или ✗ при каждом вводе.

### Критерии готовности

- getPasswordChecks возвращает hasMinLength, hasDigit, hasNoSpaces.
- Длина минимум 8; хотя бы одна ASCII-цифра; нет обычного пробела.
- Начальное поле пустое: ✗, ✗, ✓.
- Не использовать trim: проверяем введённую строку.
- Логика отдельно от интерфейса.
- React хранит только пароль, проверки вычисляет при рендере.

### Ожидаемое поведение

| Пароль | Длина | Цифра | Без пробелов |
|---|---|---|---|
| пустой | ✗ | ✗ | ✓ |
| abcdefgh | ✓ | ✗ | ✓ |
| abcdefg1 | ✓ | ✓ | ✓ |
| abc def1 | ✓ | ✓ | ✗ |

### Крайние случаи

- Пустая строка.
- Цифра в конце.
- Пробел внутри и на краю.

## Пошаговый разбор

1. Проверить length >= 8.
2. Перебрать символы for...of.
3. При первой цифре установить флаг и выполнить break.
4. Получить !password.includes(' ').
5. Вернуть объект.
6. DOM: слушать input и менять textContent.
7. React: хранить ввод и строить JSX из проверок.

## Типичные ошибки

- Number(' ') равен 0 и ошибочно считает пробел цифрой.
- trim скрывает ввод пользователя.
- Отдельные состояния проверок требуют синхронизации.

## Альтернативный способ

Регулярное выражение /[0-9]/.test(password) короче цикла: класс [0-9] ищет ASCII-цифру. Цикл проще объяснить на знакомых конструкциях.

## Проверка

Сопоставь результаты с таблицей выше и проверь каждый крайний случай. Для неизменяемых обновлений дополнительно проверь сохранение исходных данных и отсутствие влияния на соседние элементы.

Вторая реализация той же задачи: [React](../../react/task-6/README.md).

```js
// Правила не зависят от DOM: функция получает строку и возвращает boolean.
function getPasswordChecks(password) {
  let hasDigit = false;
  for (const character of password) {
    // Ищем именно ASCII-цифры; Number(" ") здесь применять нельзя.
    if ("0123456789".includes(character)) {
      hasDigit = true;
      break; // Одной цифры достаточно.
    }
  }
  return {
    hasMinLength: password.length >= 8,
    hasDigit,
    // Проверяем обычный пробел; trim скрывал бы нарушение на краях.
    hasNoSpaces: !password.includes(" "),
  };
}

// Альтернатива использует регулярное выражение.
// [0-9] обозначает одну цифру, test возвращает boolean.
function getPasswordChecksWithRegex(password) {
  return {
    hasMinLength: password.length >= 8,
    hasDigit: /[0-9]/.test(password),
    hasNoSpaces: !password.includes(" "),
  };
}
const input = document.getElementById("password");
const lengthCheck = document.getElementById("length-check");
const digitCheck = document.getElementById("digit-check");
const spacesCheck = document.getElementById("spaces-check");

function renderChecks() {
  const checks = getPasswordChecks(input.value);
  // textContent выводит текст, а не интерпретирует его как HTML.
  lengthCheck.textContent = (checks.hasMinLength ? "✓" : "✗") + " Не менее 8 символов";
  digitCheck.textContent = (checks.hasDigit ? "✓" : "✗") + " Есть цифра";
  spacesCheck.textContent = (checks.hasNoSpaces ? "✓" : "✗") + " Нет обычных пробелов";
}
input.addEventListener("input", renderChecks);
renderChecks(); // Пустое поле: ✗, ✗, ✓.
```
