# JavaScript: группировка статей по категориям
Выпуск: 11 ноября 2026.

## Условие
CMS возвращает плоский список: 1 «Состояние» React; 2 «Коллекции» Webflow; 3 «Формы» React; 4 «События» JavaScript; 5 «Динамические страницы» Webflow.
Напиши groupArticles(items), возвращающую массив { category, items } для секций каталога.
Порядок групп — по первому появлению категории; порядок карточек внутри — исходный. Ожидается React [1,3], Webflow [2,5], JavaScript [4].
Контракт: поля заполнены, category — непустая строка; категории сравниваются точно, с учётом регистра. Нормализация не требуется.
Готово: новые массив и объекты групп, новые массивы их items; входной массив/статьи не меняются. Статьи внутри результата остаются исходными объектами, глубокое копирование не требуется.
Крайние случаи: одна категория встречается не подряд; все статьи одной категории; пустой массив.
Время: 20–25 минут.

## Как рассуждать
1. Почему массив групп удобен для отображения секций?
2. Как понять, встречалась ли категория?
3. Допустимы ли push внутри чистой функции?

## Примеры ответов вслух
«Верну массив групп в порядке первого появления. Его можно напрямую отрисовать через map, не выполняя дополнительную сортировку».
«В reduce использую новый массив-аккумулятор. Через find проверю, создана ли группа. Если нет, добавлю её; если есть, добавлю статью во внутренний массив».
«push меняет только новые массивы, созданные внутри функции. Входные объекты я читаю и сохраняю по ссылке. Это не глубокая копия; сама группировка статьи не меняет».
«Верну groups на каждом шаге reduce, включая добавление в существующую группу. Проверю непоследовательные категории, порядок ID и пустой ввод».

## Пошаговый разбор
1. Начни reduce с [].
2. Найди группу по category.
3. Если нашлась, добавь статью в её items.
4. Если нет, создай { category, items:[article] }.
5. Верни аккумулятор.

Ошибки: каждый раз создавать новую группу; забыть return в reduce; сортировать исходный список; считать результат глубокой копией; менять article.category.
Проверки: React [1,3], Webflow [2,5], JavaScript [4]; два одинаковых category → одна группа; [] → []; исходный список сохраняет порядок 1,2,3,4,5.
Альтернатива: Map с категорией как ключом. Порядок вставки сохраняется, поиск группы по ключу обычно эффективнее повторного find. Но потребуется знакомство с Map и преобразование его значений в массив. Для небольшого списка выбран знакомый reduce/find; в худшем случае повторные поиски дают квадратичное число сравнений.

### script.js

```js
const articles = [
  { id: 1, title: "Состояние", category: "React" },
  { id: 2, title: "Коллекции", category: "Webflow" },
  { id: 3, title: "Формы", category: "React" },
  { id: 4, title: "События", category: "JavaScript" },
  { id: 5, title: "Динамические страницы", category: "Webflow" },
];

function groupArticles(items) {
  // Аккумулятор — новый массив групп, принадлежащий этой функции.
  return items.reduce((groups, article) => {
    const group = groups.find(
      (item) => item.category === article.category
    );

    if (group) {
      // Меняем только новый внутренний массив группы.
      // Исходная статья и входной массив остаются прежними.
      group.items.push(article);
    } else {
      // Первое появление категории задаёт позицию её группы.
      groups.push({
        category: article.category,
        items: [article],
      });
    }

    // reduce должен получить аккумулятор для следующего шага.
    return groups;
  }, []);
}

// Группы: React [1,3], Webflow [2,5], JavaScript [4].
// Порядок статей внутри групп сохраняется.
console.log(groupArticles(articles));
console.log(groupArticles([])); // Пустой вход → пустые группы.
console.log(articles); // Исходный массив не изменён.
```
